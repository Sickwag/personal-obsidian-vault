### 1988. C++中值传递和引用传递的区别？
1）值传递：在函数调用时，会触发一次**参数的拷贝动作**，所以对参数的修改不会影响原始的值。如果是较大的对象，复制整个对象，效率较低。
2）引用传递：函数调用时，函数接收的就是参数的引用，不会触发参数的拷贝动作，效率较高，但对参数的修改会直接作用于原始的值。

通过函数栈帧角度理解：
首先，不管是值传递还是引用传递，本质都是在被调用函数中，在栈区开辟一块空
间，往这块空间中填入某一个值。
值传递和引用传递不同的是，在往局部的栈空间中填入的值是不同的，以及**对这个栈空间中局部变量操作时进行的动作**是不同的
- 值传递：传递过程中，会对实参的值进行一次拷贝，借助函数栈帧的创建过程，填入函数的局部变量空间中，后续函数中对这个变量的操作，都是修改函数局部栈空间中值，并不会影响到实参，因根本不会通过实参的存储地址进行操作。
- 引用传递：传参时，也会往函数局部栈空间填入值，但这里填的是引用变量的地址，后续在对函数里的形参操作时，都会通过**间接寻址**的方式操作到实参。
- 从编译的角度看，生成符号表时，会在符号表中填入变量名和对应的地址。值传递的形参对应的地址是实参变量的地址，而这个地址中内容是可以改变的。而引用变量名对应的地址是引用对象的地址，符号表一经生成无法改变，**所以引用变量不能更改引用的对象**

### 1989. C 和 C++的区别
1）面向对象还是面向过程：
- C 语言是一门面向过程的语言，侧重于通过过程（函数）来解决问题。
- C++是一门多范式语言，主要支持面向对象，侧重于使用类和对象来组织代码。
2）继承：
- C++支持继承，允许一个子类继承一个或多个父类，达到代码复用的目的。
- C 语言中没有继承的概念。
3）函数重载：
- C++支持函数通过参数类型和参数个数的重载。
- C 语言不支持重载，函数名必须唯一才行。
4）模板：
- C++支持模板，支持静态和动态形式的多态。
- C 语言对此都不支持。
5）内存管理：
- C++使用 new 和 delete 操作符来管理内存，也支持使用智能指针来动态管理内存。
- C 语言需要使用 malloc 和 free 来申请和释放内存。
### 1990. 什么是 C++的左值和右值？有什么区别？
- 左值：可以出现在赋值运算符的左边，并且可以被取地址，通常是有名字的变量
- 右值：不能出现在赋值运算符的左边，不可
以被取地址，表示一个具体的数据值，通常是常量、临时变量
- 左值：可以放到等号左边的东西叫左值，可以取地址并且有名字
- 右值：不可以放到等号左边的东西就叫右，不可以取地址并且没有名字
可以使用 `std::move` 将***左值变为右值***
**左值引用**：当你需要修改对象的值，或者需要引用一个**持久对象**时使用。
**右值引用**：当你需要处理一个临时对象，并且想要**避免复制**，或者实现移动语义时使用。

纯右值属于右值。运算表达式产生的临时变量、不和对象关联的原始字面量、非引用返回的临时变量、lambda 表达式等都是纯右值。
举例：
- 除字符串字面值外的字面值
- 返回非引用类型的函数调用
- 后置自增自减表达式 i++、i--
- 算术表达式 (`a+b, a*b, a&&b，a==b` 等)
- 取地址表达式等 (&a)
### 1991. 什么是 C++的移动语义和完美转发？
一种优化资源管理的机制。常规的资源管理是拷贝别人的资源。而移动语义是转移所有权，转移了资源而不是拷贝资源，性能会更好。移动语义通常用于那些**比较大的对象**，搭配移动构造函数或移动赋值运算符来使用。
```cpp
class A {
public:
    A(int size) : size_(size) {
        data_ = new int[size];
    }
    A(){}
    A(const A& a) {  // 左值引用
        size_ = a.size_;
        data_ = new int[size_];
        cout << "copy " << endl;
    }
    A(A&& a) { // 右值引用
        this->data_ = a.data_;
        a.data_ = nullptr;
        cout << "move " << endl;
    }
    ~A() {
        if (data_ != nullptr) {
         delete[] data_;
        }
    }
    int *data_;
    int size_;
};
int main() {
    A a(10);
    A b = a;
    A c = std::move(a); // 调用移动构造函数，接受右值，但将c中资源指向a，a中不再含有指向资源的指针，只需要修改指针而不用拷贝数据
    return 0;
}
```
所有 C++ stl 都实现了移动语义，本质上是**偷走别人指向别人资源的指针**，
```cpp
std::vector<string> vecs;
...
std::vector<string> vecm = std::move(vecs); // 免去很多拷贝
```
可以参考 [[Modern C++#移动语义]]

完美转发指可以写一个接受任意实参的函数模板，并转发到其它函数，目标函数会收到与转发函数完全相同的实参，转发函数实参是左值那目标函数实参也是左值，转发函数实参是右值那目标函数实参也是右值
核心实现是：转发引用（`T&&`）+ `std::forward<T>(arg)`
```cpp
void PrintV(int &t) { cout << "lvalue" << endl; }
void PrintV(int &&t) { cout << "rvalue" << endl; }
template<typename T>
void Test(T &&t) {
    PrintV(t);
    PrintV(std::forward<T>(t));
    PrintV(std::move(t));
}
int main() {
    Test(1); // 传递左值				// lvalue rvalue rvalue
    int a = 1;
    Test(a); // 传递右值 			// lvalue lvalue rvalue
    Test(std::forward<int>(a));   	// lvalue rvalue rvalue
    Test(std::forward<int&>(a));  	// lvalue lvalue rvalue
    Test(std::forward<int&&>(a)); 	// lvalue rvalue rvalue
    return 0;
}
```
可以参考 [[Modern C++#Note：完美转发]]
### 1992. 什么是 C++ 的列表初始化
使用花括号`{}`来初始化变量或对象。
可以使用初始化列表接受任意长度可以防止类型窄化，避免精度丢失的隐式类

### 1993. C++中 move 有什么作用？它的原理是什么？
函数前名为：
```cpp
// move
template <class T>
LIBC_INLINE constexpr cpp::remove_reference_t<T> &&move(T &&t) {
  return static_cast<typename cpp::remove_reference_t<T> &&>(t);
}
```
右值可以触发到类的移动构造函数或者移动赋值函数。因触发了移动构造函数或者移动赋值函数，**我们就默认，原对象后面已经不会再使用了**（包括内部的某些内存），这样我们就可以在新对象中直接使用原对象的那部分内存，减少了数据的拷贝操作
但，原对象是否不可使用，还是取决于搭配的移动构造函数和移动赋值函数是如何实现的，但使用 `std::move` 时，原对象后不可使用了
`std: move` 本身并不移动任何东西。它仅仅执行一个类型转换，将其参数转换为对应类型的右值引用。实际上是在告诉编译器你有一个对象，你打算将它作为一个右值来使用，这通常意味着你不再需要这个对象的当前值，而且这个对象的资源可以被安全地转移到另一个对象中。
移动语义是在 `std: move` 被用来将一个对象标记为可移动后，该对象参与到一个需要右值引用的上下文中时触发的。（如对象被用作另一个对象的构造函数或赋值函数的参数)
