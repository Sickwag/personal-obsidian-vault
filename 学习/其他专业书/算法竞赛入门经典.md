这个迭代过程会不断重复，直到满足一定的精度要求或达到最大迭代次数。每次迭代都会使 xn+1​ 更接近真实的平方根值。

#### 零碎
- `<cmath>` 中的 `floor(x)` 是高斯函数，得到不超过 x 的最大整数，可以解决浮点数误差问题
`int m = floor(sqrt(n) + 0.5);`
#### 代码
- 标准解
```cpp
#include <chrono>
#include <iostream>
#include <cmath>
using namespace std;
int main(){
    auto start_time = chrono::high_resolution_clock::now();
    for (int a = 1; a <= 9; a++){
        for (int b = 0; b <= 9; b++){
            int n = a * 1100 +  b * 11;
            int m = floor(sqrt(n) + 0.5);
            if (m * m == n){
                cout << n;
            }
        }
    }
    auto end_time = chrono::high_resolution_clock::now();
    auto duration = chrono::duration_cast<chrono::nanoseconds>(end_time - start_time);
    cout << "\n"
         << duration.count() << "\n";
}
```

- 自己解
```cpp
#include <chrono>
#include <iostream>
#include <vector>
using namespace std;
int main(){
    vector<int> vec = {};
    for (int i = 32; i <= 99; i++){
        vec.push_back(i * i);
    }
    auto start_time = chrono::high_resolution_clock::now();
    int result = 0;
    for (int a = 1; a <= 9; a++){
        for (int b = 0; b <= 9; b++){
            result = a * 1100 + b * 11;
            for (int x : vec){
                if(result == x)
                    cout << result << " ";
            }
        }
    }
    auto end_time = chrono::high_resolution_clock::now();
    auto duration = chrono::duration_cast<chrono::microseconds>(end_time - start_time);
    cout << "\n"
         << duration.count();
}
```

#### pow 函数工作原理
1. **重复乘法**：对于较小的整数指数 `y`，最直接的方法是通过重复乘法来计算 `x` 的 `y` 次方。例如，`x^3` 可以通过 `x * x * x` 来计算。
2. **快速幂算法**：对于较大的指数，重复乘法会非常低效。快速幂算法（也称为“快速乘方”或“快速指数”算法）是一种高效的计算幂的方法，它通过将指数 `y` 表示为二进制形式，并利用二进制幂的性质来减少乘法的次数。例如，计算 `x^13` 可以分解为 `x^(8+4+1)`，即 `x^8 * x^4 * x^1`，这样只需要三次乘法。
3. **分治法**：快速幂算法本质上是一种分治策略，它将大指数问题分解为更小的子问题。在每次迭代中，它将指数除以 2，并相应地平方底数 `x`。如果指数是奇数，则还需要乘以一个 `x`。这个过程一直持续到指数变为 0 或 1。
4. **浮点数优化**：对于浮点数指数，`pow` 函数会使用更复杂的算法来处理，可能包括泰勒级数展开、对数和指数函数的近似等。这些方法可以处理非整数和负数指数的情况。
5. **数值稳定性**：在实现 `pow` 函数时，还需要考虑数值稳定性问题，特别是在处理非常大或非常小的数时。为了保证计算的准确性，可能需要使用特殊的数学技巧来避免溢出或下溢。
==当数值很小时，重复乘法和快速幂算法比较快==，但数据很复杂或者很大/小时使用 `pow` 速度很慢

### 例题 2-6 数据统计 2
- 多组数据的操作，要记得对每组数据需要的参照量在每组数据使用完后**重置**
- 嵌套的两个代码中，内层嵌套的变量会屏蔽外层变量，可能出现**隐蔽的错误**
- 使用 `{}` 可以创建一个新的作用域，内层作用域有一个和外层相同的变量就会导致屏蔽现象
#### 代码
```cpp
#include "header.h"
#include "functions.h"
#define INF  1000000
int main(){
    string w_filename = "example.txt";
    string o_filename = "example out.txt";
    ifstream ifs;
    ofstream ofs;
    int number = 0;
    ifs.open(w_filename,ios::in);
    ofs.open(o_filename,ios::out);
    while(ifs >> number && number){
        int min = INF;
        int max = -INF;// 重置最大最小值，不然每次循环最大最小是继承上一循环的
        for (int i = 0; i < number;i++){
            int input = 0;
            ifs >> input;
            if(input < min )
                min = input;
            if(input > max)
                max = input;
```
