### 列表推导式
```Python
[ ord(ch)  for ch in 'WASDRQwasdrq' ]
  ↑        ↑      ↑
  表达式    变量    可迭代对象
```
`letter_codes = [ord(ch) for ch in 'WASDRQwasdrq']` 这行代码的完整作用是：
创建一个新的列表 `letter_codes`，其中包含了字符串 `'WASDRQwasdrq'` 中每个字符的 Unicode 码点。
换句话说，它会把字符 'W', 'A', 'S', 'D', 'R', 'Q', 'w', 'a', 's', 'd', 'r', 'q' 分别通过 `ord()` 函数转换为它们对应的数字编码，并将这些数字编码依次放入 `letter_codes` 列表中。

### 一等公民概念
- **Python 函数是“一等公民” (First-class citizens)**
    
    这是 Python 及其它函数式编程语言的一个核心概念。 “一等公民” 指的是，在编程语言中，函数与普通的数据类型（如整数、字符串等）具有同等的地位。 这意味着：
    
    1. 函数可以赋值给变量：就像你可以将数字赋值给变量一样，你也可以将函数赋值给变量。例如 action = game`，，此时变量 ction` 就指向了 `game` 函数。
    2. 函数可以作为参数传递给其他函数： 这使得高阶函数 (接受函数作为参数或返回函数的函数) 成为可能。
    3. 函数可以作为返回值从函数中返回： 这也是高阶函数的特性。
    4. 函数可以存储在数据结构中：例如，可以将函数存储在列表、字典等数据结构中，就像 `state_actions` 字典所做的那样。
- **C++ 与 Python 的对比：函数指针、函数对象、`std::function`**
    在 C++ 中，函数名在大多数情况下会被隐式转换为 **函数指针 (function pointer)**。 但 C++ 中的函数指针类型比较复杂，且功能有限。 为了更灵活地处理函数，C++ 引入了 **函数对象 (functor)** 和 **`std::function` (C++11)**。
    - **函数指针**： C++ 中可以使用函数指针来指向函数的地址，然后通过函数指针调用函数。 但函数指针类型不够灵活，声明语法也比较繁琐。
    - **函数对象 (functor)**： 函数对象是重载了 `operator()` 的类或结构体的实例。 函数对象可以像函数一样被调用，并且可以携带状态。
    - `std::function` (C++11)： `std::function` 是一个通用的函数包装器，可以包装各种可调用对象，包括函数指针、lambda 表达式、函数对象、成员函数指针等。 `std::function` 类型更加灵活和易用，是 C++ 中处理函数对象更推荐的方式。
        
    
    **C++ 中不能像 Python 那样直接将函数名赋值给变量，然后直接调用。** 如果你想在 C++ 中实现类似 Python 的函数“一等公民”的效果，你需要使用函数指针、函数对象或 `std::function` 来间接表示和操作函数。 C++ 中如果直接写 `init` (函数名) 赋值给变量，通常会被解释为函数指针的隐式转换，但直接使用函数名作为变量名本身在某些语境下可能并不被允许，或者含义与Python中直接使用函数名作为对象不同。 C++ 更强调类型安全和编译时检查，因此对函数类型的处理相对更显式和严格。
