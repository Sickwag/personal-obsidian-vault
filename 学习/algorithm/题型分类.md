核心思想就是不同时间点（或者说位置，数组下标等具有唯一性的，不同节点互不影响但有固定顺序）会发生状态改变，每一个状态的**改变行为**是一个事件，可以通过记录每一个节点的状态**并更新状态**，再按照行为的出现顺序（或者说节点应该有的的顺序）处理每一个节点

## 区间求和&数组修改&查询
对于各类「区间求和」问题，该用什么方式进行求解，之前在[这里](https://leetcode.cn/problems/range-sum-query-mutable/solutions/632515/guan-yu-ge-lei-qu-jian-he-wen-ti-ru-he-x-41hv/)提到过。
此处可以再总结一下（加粗字体为最佳方案）：

数组不变，求区间和：「前缀和」、「树状数组」、「线段树」
多次修改某个数（单点），求区间和：「树状数组」、「线段树」
多次修改某个区间，输出最终结果：「差分」
多次修改某个区间，求区间和：「线段树」、「树状数组」（看修改区间范围大小）
多次将某个区间变成同一个数，求区间和：「线段树」、「树状数组」（看修改区间范围大小）
只有在我们遇到第 4 类问题，不得不写「线段树」时，我们才考虑线段树。

因「线段树」代码很长，而且常数很大，实际表现不算很好。我们只有在不得不用时才考虑「线段树」。所以优先级为：
1. 简单求区间和，用「**前缀和**」
2. 多次将某个区间变成同一个数，用「**线段树**」
3. 其他情况，用「**树状数组**」

存在经过一些经过“额外”操作，对问题进行转化，从而使用别的解决方案求解的情况，但解题过程也可能是奖这些题目转化成以上模型

### 双指针法
双指针解法利用了数学中“不动点原理”：
![[Pasted image 20250227003129.png]]

> 证明每个循环的数字都是一样的，我们可以使用数学中不动点理论。在一个有限的系统中，重复应用一个确定的操作最终会达到一个循环，这是因**系统的状态是有限的**。在快乐数的情况下，由于每次计算都是基于有限的数字（0-9）的平方，因此可能的结果也是有限的。这意味着，如果我们从某个数字开始，不断重复计算它的各位数字的平方和，最终**必然会进入一个循环**，因可能的**平方和是有限的，而且每次计算都是确定性的**。
>
> 此外，由于**每个非快乐数都会进入一个固定的循环**，而这个循环**不包含 1**，这意味着循环中所有数字都是固定的，*从进入循环的第一个数开始，整个环中数字只有唯一一种确定形式*，不同的循环中相同数字的下一个数一定一样，只是环的大小不一样
>
> 综上所述，我们可以得出结论，对于非快乐数，它们在重复计算各位数字的平方和的过程中不仅会形成一个循环，而且每个循环中数字都是一样的。这一结论是基于有限性原理和确定性操作的重复应用。

如果这样做，您会发现只有一个循环：4→16→37→58→89→145→42→20→4。**所有其他数字都在进入这个循环的链上**（非快乐数），或者在进入 1 的链上（快乐数），所以一旦再循环中发现这个数组中任何一个数字，立刻可以判定他是一个非快乐数避免死循环
```csharp
class Solution {
    public int getNext(int n) {
        int totalSum = 0;
        while (n > 0) {
            int d = n % 10;
            n = n / 10;
            totalSum += d * d;
        }
        return totalSum;
    }
    public bool IsHappy(int n) {
        HashSet<int> cycleMembers =
            new HashSet<int>(new int[8] {4, 16, 37, 58, 89, 145, 42, 20});

        while (n != 1 && !cycleMembers.Contains(n)) {
            n = getNext(n);
        }
        return n == 1;
    }
}
```

回溯法，一般可以解决如下几种问题：
- 组合问题：N个数里面按一定规则找出k个数的集合
- 切割问题：一个字符串按一定规则有几种切割方式

```cpp
        dp[0] = 1;
```

## 贪心算法
#### 贪心策略与背包、 DP 区分
有两种基本贪心策略：
-   从最小/最大开始贪心，优先考虑最小/最大的数，从小到大/从大到小贪心。在此基础上，衍生出了反悔贪心。
-   从最左/最右开始贪心，思考第一个数/最后一个数的贪心策略，把 n 个数的原问题转换成 n−1 个数（或更少）的子问题。 思考方向
1.  回想一下高考数学的最后一题，三个小问，前两小问让你计算一些特殊情况，第三小问让你计算/证明一个一般的结论。这其实就是从特殊到一般的思考方式，
2.  做算法题（尤其是思维题和构造题）时，也可以从最简单、最特殊的情况开始，去探索题目的性质，逐渐过渡到一般情况。
-   小型数组：nums 只有 1 个数？只有 2 个数？只有 3 个数？
-   万里挑一：nums 所有数都相同？只有一个数不一样？有两个数不一样？某个数特别大？
-   黑白世界：只有两种数？例如 [0,1,0,1,0,1] 或者 ababab。
-   反向思考：如果答案是 1，输入会是什么样的？如果答案是 2？是 nums[0]？是 nums[1]？
-   枚举归纳：试试小范围打表，暴力枚举所有情况，找规律。
-   思考这些特殊情况，有时会产生求解原问题的灵感。
-   如 [[#1833. 雪糕的最大数量]]，所有的 **石头**、**雪糕**之类的物品，如果对答案贡献度为 1（答案要求统计数量，次数等），使用一般使用贪心
-   如果选择每样物品，即**选石头，买雪糕这个动作**有不同的消耗，考虑用 01 背包最好，但复杂度为 O (N×C)，其中 N 为物品数量（数量级为 10^5）如果通过复杂度可能 TLE，向贪心考虑
-   如果每样东西有价值 value，求选物品的方案，求最大的 value 总和，可以背包

## 并查集
基本知识讲解：[【算法与数据结构】—— 并查集-CSDN博客](https://blog.csdn.net/the_zed/article/details/105126583)
并查集是一种**树型的数据结构**，用于处理一些不相交集合的合并及查询问题（即所谓的并、查）。比如说，我们可以用并查集来判断一个森林中有几片树林、某一棵树是否属于某片树林等。
### 基本原理
模板题可以参考[[刷题路线#洛谷#P8654 合根植物]]
并查集主要由一个整型数组 `pre[ ]` 和两个函数 `find()`、`join()` 构成。
数组 `pre[ ]` 记录了每个点的前驱节点是谁，函数 `find(x)` 用于查找指定节点 x 属于哪个集合，函数 ` join(x,y)` 用于合并两个节点 x 和 y 。
#### find 函数-->查找一个连通分量主节点（门派教主）
如何判断一个人属于哪一个门派？--> 根据门派教主是谁区分
如何找到一个门派的教主？-->find 函数用来查找
```cpp
int find(int x)	{				// 查找 x 的教主
	while(pre[x] != x)			// 如果x的上级不是自己（则说明找到的人不是教主）
		x = pre[x];				// x 继续找他的上级，直到找到教主为止
	return x;					// 教主驾到~~~
}
```
#### join 函数 --> 连通分量中加入新的节点（添加门派新人&合并门派）
合并门派方法
```cpp
void join(int x,int y) {                   // 我想让虚竹和周芷若做朋友（功能：将两个节点 x 和 y 合并到一棵树中）
    int fx=find(x), fy=find(y);            // 虚竹的老大是玄慈，芷若MM的老大是灭绝（寻找 x, y 的代表元）
    if(fx != fy)                           // 玄慈和灭绝显然不是同一个人（如果 x 和 y 的代表元不相等）
        pre[fx]=fy;                        // 方丈只好委委屈屈地当了师太的手下啦（则将 x 的代表元设置为 y 的代表元）
}
```

```cpp
int find(int x) {    			// 查找结点 x 的根结点
    if(pre[x] == x) return x;		// 递归出口：x 的上级为 x 本身，即 x 为根结点
    return pre[x] = find(pre[x]);	// 此代码相当于先找到根结点 rootx，然后 pre[x]=rootx
}
```
**缺陷**：如果拿到手的一个图是一个**成品图**（leetcode 的 io 代码评判规则中参数中直接给出），第一次调用 find 查找没有路径压缩效果，因调整路径（将新人（也就是发起 find 的主题）归属于教主）的操作是在 find 函数中执行的。所以**即使第二次 find 操作和第一次 find 查询同样的目标，第二次也会比第一次快**。
如果不是高频重复查找，这一方法和普通遍历**在复杂读上**没有区别。
这种方法适用于**逐步建立图**（ACM iio 类型）时使用，每次输入两个节点的关系就调用一次 `unite` 函数，参考[[刷题路线#洛谷#并查集#P8654 合根植物]]，逐步建立图后再查查询

```cpp
        pre[i] = i;     			// 每个结点的上级都是自己
        rank[i] = 1;    			// 每个结点构成的树的高度为 1
    }
}

void union(int x,int y) {
    x=find(x);							// 寻找 x 的代表元
    y=find(y);							// 寻找 y 的代表元
    if(x==y) return ;					// 如果 x和 y 的代表元一致，说明他们共属同一集合，则不需要合并，直接返回；否则，执行下面的逻辑
    if(rank[x]>rank[y]) pre[y]=x;		// 如果 x的高度大于 y，则令 y 的上级为 x
    else {
        if(rank[x]==rank[y]) rank[y]++;	// 如果 x 的高度和 y 的高度相同，则令 y 的高度加1
        pre[x]=y;						// 让 x 的上级为 y
    }
}
```
这种方法总是将小树合并到大树下，保证树的高度最多为 $O(\log n)$ ^[1]，总复杂度：$O((m \times n + k) \cdot \alpha(n))$。
注意，union 函数逻辑不能将 else 中逻辑拆分为：
```cpp
void unite(int x, int y) {
    int root_x = find_root(x);
    int root_y = find_root(y);
    if(root_x == root_y)
        return;
    if (node_rank[root_x] > node_rank[root_y]) {
        pre[root_y] = root_x;
    }else if(node_rank[root_x] == node_rank[root_y]){
        node_rank[root_y]++;
    }else{
    	// node_rank[root_y]++;
        pre[root_x] = root_y;
    }
}
```
这样改变了原意，需要解开注释

---
[1]: 若两棵树秩相同，合并后新树的秩加 1（高度增加 1），若秩不同，矮树合并到高树下，高度不变。

#### 两种方法比较
| 优化点    | 原始解法            | 优化后解法                 |
| ------ | --------------- | --------------------- |
| 路径压缩   | 仅在 `find` 中实现   | 同左                    |
| 按秩合并   | 无               | 引入 `rank` 数组优化合并顺序    |
| 树的高度控制 | 可能较高（最坏 $O(n)$） | 严格保证 $O(\log n)$，实际更低 |
| 代码复杂度  | 简单              | 略复杂（需维护 `rank`）       |
## 暴力递归

递归核心思想是分解问题父得到相似的子问题，子问题的最简单形式可以直接得到
这一点用在斐波那契数列中就是如果求的是：
- 每个数等于前两个数字之和
- 如果求第一个和第二个数字可以直接得到答案 1

所以问题转化为：
- 将每个数字视为最终可由第一和第二个数得到（直接结果）
- 将每个父问题分解成类似父问题但更接近直接结果的形式
递归需要注意重复问题（可以通过观察公式，如果有的话）

```cpp
int factorial(int n) {
    if (n == 1) return 1;
    return n * factorial(n - 1);
}
int fibonacci(int n, vector<int>& record) {
    if (n == 0 || n == 1) {
        return 1;
    }
    if (record[n] != -1) return record[n];
    record[n] = fibonacci(n - 1, record) + fibonacci(n - 2, record);
    return record[n];
}
int main() {

    cin >> length;
    vector<int> record(length + 1, -1);
    cout << fibonacci(length, record);
    cout << factorial(5);
}
```

## 树状数组
本质：一种支持 **单点修改** 和 **区间查询** 的，代码量小的**数据结构**。
特点：
- 树状数组能解决的问题是**线段树能解决的问题的子集**：树状数组能做的，线段树一定能做；线段树能做的，树状数组不一定可以。然而，树状数组的代码要远比线段树短，时间效率常数也更小，因此仍有学习价值
- 在差分数组和辅助数组的帮助下，树状数组还可解决更强的 **区间加单点值** 和 **区间加区间和** 问题

#### 链表（链式存储）基本原理
链表和数组的转化 （单链表和双链表通用）
```cpp
class ListNode {
public:
    int val;
    ListNode *next,*pre;
    ListNode(int x) : val(x), next(NULL) , pre(NULL){}
};
// 输入一个数组，转换为一条单链表
ListNode* createLinkedList(vector<int> arr) {
    if (arr.empty()) {
        return nullptr; // 这一步比较重要
    }
    ListNode* head = new ListNode(arr[0]);
    ListNode* cur = head;
    for (int i = 1; i < arr.size(); i++) {
    	// 单链表
        cur->next = new ListNode(arr[i]);
        cur = cur->next;
        // 双链表
        DoubleListNode* newnode = new DoubleListNode(arr[i]);
        cur->next = newnode;
        newnode->pre = cur;
        cur = cur->next;
    }
    return head;
}
// 将链表转化为数组
vector<int> listToVector(ListNode* head) {
    vector<int> result; // 用于存储链表值的 vector
    ListNode* current = head; // 当前节点指针
    // 遍历链表
    while (current != nullptr) {
        result.push_back(current->val);
        current = current->next;
    }
    return result; // 返回结果 vector
}
```
