## 事件—状态法
核心思想就是不同时间点（或者说位置，数组下标等具有唯一性的，不同节点互不影响但有固定顺序）会发生状态改变，每一个状态的**改变行为**是一个事件，可以通过记录每一个节点的状态**并更新状态**，再按照行为的出现顺序（或者说节点应该有的的顺序）处理每一个节点
### 上下车问题
#### 1094. 拼车
(https://leetcode.cn/problems/car-pooling/)
[[刷题路线#1094. 拼车|上下车问题]]中，每个站点（时间点）车上的乘客人数是一个状态，每个站点之间除了顺序（位置）固定没有联系，每到一个站点更新一次状态

```cpp
struct Event {// mark1
    int position;
    int passengers;
    bool is_pickup; // true for pick ,false for drop
};
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
        vector<Event> events;
        for(auto& x : trips){// mark2
            int num = x[0], from = x[1], to = x[2];
            events.emplace_back(Event{ from,num,true });
            events.emplace_back(Event{ to,num,false });
        }
        sort(events.begin(), events.end(), [&](const Event& x, const Event& y) -> bool { // mark3
            if (x.position != y.position) {
                return x.position < y.position; // 如果x的position<y的position，则x需要先处理，x.position < y.position;得到true，true表示左边事件x需要放在右边事件y的左边
            }
            return !x.is_pickup && y.is_pickup; // 表示现在的情况是有两个事件的position相同，并且是左边的事件(x)要下车，右边事件(y)上车，如果是则两者的比较结果是左边数字应该放在右边数字的左边，反之则反之
            });
        int current_passe = 0;
        for (auto event : events) {// mark4
            if (event.is_pickup) {
                current_passe += event.passengers;
                if (current_passe > capacity) {
                    return false;
                }
            }
            else {
                current_passe -= event.passengers;
            }
        }
        return true;
    }
};
```
- 车经过的站点有内在的位置，是**固有的顺序**，每个站点车上的人数是**状态**
- 上下车的**行为**会改变状态，是一个**事件**
- 行为之间的联系只有时间关系，符合固有顺序
---
- mark 1定义每一个改变状态的事件
- mark 2 记录所有的事件
- mark 3 按照状态出现顺序排列事件（**最关键的一步**）
- mark 4 根据**按顺序出现的事件**还原每一个状态
本体也可以使用[[刷题路线#差分|差分]]方法解决

## 区间求和&数组修改&查询
对于各类「区间求和」问题，该用什么方式进行求解，之前在[这里](https://leetcode.cn/problems/range-sum-query-mutable/solutions/632515/guan-yu-ge-lei-qu-jian-he-wen-ti-ru-he-x-41hv/)提到过。
此处可以再总结一下（加粗字体为最佳方案）：

数组不变，求区间和：「前缀和」、「树状数组」、「线段树」
多次修改某个数（单点），求区间和：「树状数组」、「线段树」
多次修改某个区间，输出最终结果：「差分」
多次修改某个区间，求区间和：「线段树」、「树状数组」（看修改区间范围大小）
多次将某个区间变成同一个数，求区间和：「线段树」、「树状数组」（看修改区间范围大小）
只有在我们遇到第 4 类问题，不得不写「线段树」的时候，我们才考虑线段树。

因「线段树」代码很长，而且常数很大，实际表现不算很好。我们只有在不得不用的时候才考虑「线段树」。所以优先级为：
1. 简单求区间和，用「**前缀和**」
2. 多次将某个区间变成同一个数，用「**线段树**」
3. 其他情况，用「**树状数组**」

存在经过一些经过“额外”操作，对问题进行转化，从而使用别的解决方案求解的情况，但解题过程也可能是奖这些题目转化成以上模型

#### 209. 长度最小的子数组
(https://leetcode.cn/problems/minimum-size-subarray-sum/)
前缀和+二分查找做法：
```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        vector<int> pre_sum(n + 1, 0); // 前缀和数组
        partial_sum(nums.begin(), nums.end(), pre_sum.begin() + 1);
        int min_length = INT_MAX;
        for (int i = 1; i <= n; i++) {
            int to_find = pre_sum[i] - target;
            auto it = upper_bound(pre_sum.begin(), pre_sum.end(), to_find);
            if (it != pre_sum.begin()) {
                int j = it - pre_sum.begin() - 1;
                min_length = min(min_length, i - j);
            }
        }
        return min_length == INT_MAX ? 0 : min_length;
    }
};
```
- 不使用 `lower_bound`，否则需要一个 if 来判断下标是否要+1
- 不需要使用 map 等**有序容器**装前缀和数组，元素都>0，自然有序
```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size(), left = 0, right = 0, sum = 0, length = INT_MAX;
        for (right; right < n;right++) {
            sum += nums[right];
            while (left <= right&&sum >= target) {
                length = min(length, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }
        return length == INT_MAX ? 0 : length;
    }
};
```
- 其实可以不用写 `left <= right`，因题目中说明 target 是正数，所以当 `left==right ` 时 `sum==0` 不会等于 target，但如果 left 可能超过 right 则一定要加，参考 [[#713. 乘积小于 K 的子数组]]，保险期间滑动窗口题目还是都加上
- 滑动窗口一般都是有规律的，要么[[#测试数据是正数|数组是有序的]]，要么元素都是正数有[[#测试数据是正数|单调性]]

前缀和做法：
```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0;
        int n = nums.size(), count = 0, left = 0;
        vector<long long> pre_multi(n + 1, 1);
        partial_sum(nums.begin(), nums.end(), pre_multi.begin() + 1, [](const int a, const int b) {
            return a * b;
            });
        for (int right = 0;right < n;right++) {
            long long to_find = pre_multi[right + 1] / k;
            auto it = upper_bound(pre_multi.begin(), pre_multi.begin() + right + 1, to_find);
            if (it != pre_multi.end()) {
                int temp = it - pre_multi.begin();
                count += right + 1 - temp;
            }
        }
        return count;
    }
};
```
同上一题一样套路，由于前缀和数组具有单调性，先计算前缀和，再通过二分查找遍历前缀和，由于计算前缀积，导致 long long 数组仍溢出，所以用[[用法导向知识#精度和数据溢出|浮点数溢出取余方法]]
```cpp
class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0;
        int n = nums.size(), ret = 0;
        vector<double> logPrefix(n + 1);
        for (int i = 0; i < n; i++) {
            logPrefix[i + 1] = logPrefix[i] + log(nums[i]);
        }
        double logk = log(k);
        for (int j = 0; j < n; j++) {
            int l = upper_bound(logPrefix.begin(), logPrefix.begin() + j + 1, logPrefix[j + 1] - log(k) + 1e-10) - logPrefix.begin();
            ret += j + 1 - l;
        }
        return ret;
    }
};
```

```cpp
class Solution {

        long long multi = 1;
        for (int right = 0;right < n;right++) {

                left++;
```

### 滑动窗口（窗口大小不变）
滑动窗口的一般思路是
- 一遍循环，控制窗口的结束位置
- 用另一个变量控制窗口大小

	- 对遍历过程中出现符合的元素进行标记，一般通过哈希表的 `value` 字段

#### 219. 存在重复元素 II
(https://leetcode.cn/problems/contains-duplicate-ii/)
使用经典思路：
```cpp
class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        // 哈希表用于存储滑动窗口内的元素
        unordered_set<int> window;
        for(int i = 0; i < nums.size(); ++i){
            // 检查当前元素是否已经在窗口中
            if(window.find(nums[i]) != window.end()){
                return true;
            }
            // 将当前元素插入到窗口中
            window.insert(nums[i]);
            // 如果窗口大小超过k，移除最左边的元素
            if(window.size() > k){
                window.erase(nums[i - k]);
            }
        }
        // 如果没有找到符合条件的元素
        return false;
    }
};
```
- 必须配合哈希表使用 `find` 维持在 `O(1)`
- 使用擦除操作，尽量减小空间占用，k 很大（或者等于 `nums.size()`）时虽然 `find` 时间不变但 windows 的大小在变大
- **三个操作的顺序不能改变**啊，如果 1,2 步改变，则重复元素插入 unordered_set 中会报错
- 如果新增操作放在查找操作后面，**可以不用考虑匹配到自身这一种可能** ^23 a 341
- 经典做法的步骤：检查是否在窗口中——窗口中插入元素——窗口溢出处理
使用判断访问次数思路： ^8 cbbd 4
```cpp
class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        int n = nums.size();
        unordered_map<int, bool> set;
        for(int i = 0; i < n; ++i){
            if(i > k) // mark 1
                set[nums[i - k - 1]] = false;
            if(set[nums[i]]) // mark 2
                return true;
            set[nums[i]] = true; // mark 3
        }
        return false;
    }
};
```
这种做法关键在于**窗口的大小在 mark 3 执行之前是<=k**的，窗口中元素一定是 `true`，是哈希表中 `value==true` 的所有键值对
- mark 3 一定要放在 mark 2 之后，否则必定 `return true`，mark 1 一定要放在 mark 2 前，否则窗口大小溢出
- 在 mark 3 中对哈希表中一个元素进行访问并设置为 true，表示访问过一次
- mark 2 在下一次循环中在 mark 3 之前，执行 mark 2 为 `true` 表示访问一个元素时发现他已经被访问过一次了
- 由于 remove 哈希表元素会导致 i 下标错误，所以只能任由 `set` 增大，空间复杂度较高
- 这种做法比较局限于**统计某一个元素的出现一次以上的次数**
可以通过下面的方法自定义出现次数
```cpp
class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k,int count = 3) {
        int n = nums.size();
        unordered_map<int, pair<int,bool>> set;
        for(int i = 0; i < n; ++i){
            if(i > k) // mark 1
                set[nums[i - k - 1]].second = false;
            if(set[nums[i]].first == count-1&&set[nums[i]].second == true) // mark 2
                return true;
            set[nums[i]].first++;
            set[nums[i]].second = true; // mark 3
        }
        return false;
    }
};
```
通过一个 `bool` 表示该变量是否在滑动窗口内，pair 中 int 表示出现次数，但这样不如传统方法三步走比较直接

	- 第一次访问一个位置，将其中值设置为新插入的值，这样再次访问这个位置得到的是非空，**这个非空的信息可以作为标记值**，访问一次 `访问值++`（用 int 记录访问次数）
	- 也可以将访问次数设置为值的一部分，如 `pair<int,int>` first 记录上一个这个位置的更新值，seconde 记录这个位置的更新次数
	- 依然用 int 记录访问次数，并通过 `.count(key)` 方法记录容器中出现键为 key 的键值对次数，这样信息密度更高，count 的结果表示**是否访问过**，int 可以空闲出来记录别的信息, [[刷题路线#2260. 必须拿起的最小连续卡牌数]]

#### 977. 有序数组的平方
(https://leetcode.cn/problems/squares-of-a-sorted-array/)
- 简单粗暴的 O(n)算法是找到正负数分界线，定一个 left 指针从分界线向左移动（负数部分），同理 right 是正数部分
- 还需要一个辅助数组存储新的数组，因从分界线向两端遍历是从小到大的，会覆盖原有值
---
```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n);
        int i = 0, j = n - 1;
        for (int p = n - 1; p >= 0; p--) {
            int x = nums[i] * nums[i];
            int y = nums[j] * nums[j];
            if (x > y) {
                ans[p] = x;
                i++;
            } else {
                ans[p] = y;
                j--;
            }
        }
        return ans;
    }
};
```
- 在不知道分界线情况下，数组两端都是各自领域（正负）的最大值，向中间遍历（靠拢）所以可以从大到小遍历查找，每遍历一个数都是当前领域中最大的，从右向左更新即可
- `x,y` 分别记当前左右指针遍历的值，每次只更新一个位置防， x, y 只能记录一个防止覆盖
```cpp
class Solution {
public:
```

#### 11. 盛最多水的容器
(https://leetcode.cn/problems/container-with-most-water/)
分析：
- 容器中水满足*短板效应*
- 可以得到遍历公式 `S(i,j)=min(h[i],h[j])×(j−i)`
思考：
- 只有两个变量，考虑两个变量的变化情况对结果的影响
	- i 固定，j 遍历整个数组
	- j 固定，i 遍历整个数组
	- 根据某个条件依次、交替移动 i 或 j
	- 同时移动原理与上面一致
- 初始状态 i 在左，j 在右, 每次记录下 `S(i,j)` i，j 的任何一种移动都会导致 `(j−i)` 变小
- min 选出最小的，所以移动 `h[i],h[j]` 中更小的那个可能会导致 `s(i,j)` 变大或者不变 （`(j−i)` 变小，但 `min(h[i],h[j])` 变大），如果移动 `min(h[i],h[j])` 中最大的，则 `min(h[i],h[j])` 只可能变小或者不变，总体 `S(i,j)` 变小
总结
- 有固定公式可循的算法题，思考各个变量不同的变动情况分别会造成什么影响
- 求一个过程中最大值最小值问题，可以思考每一个细分过程中分别什么变量能够发生什么变化，变化会对过程结果发生什么影响

双指针解法利用了数学中“不动点原理”：
![[Pasted image 20250227003129.png]]

> 证明每个循环的数字都是一样的，我们可以使用数学中不动点理论。在一个有限的系统中，重复应用一个确定的操作最终会达到一个循环，这是因**系统的状态是有限的**。在快乐数的情况下，由于每次计算都是基于有限的数字（0-9）的平方，因此可能的结果也是有限的。这意味着，如果我们从某个数字开始，不断重复计算它的各位数字的平方和，最终**必然会进入一个循环**，因可能的**平方和是有限的，而且每次计算都是确定性的**。
>
> 此外，由于**每个非快乐数都会进入一个固定的循环**，而这个循环**不包含 1**，这意味着循环中所有数字都是固定的，*从进入循环的第一个数开始，整个环中数字只有唯一一种确定形式*，不同的循环中相同数字的下一个数一定一样，只是环的大小不一样
>
> 综上所述，我们可以得出结论，对于非快乐数，它们在重复计算各位数字的平方和的过程中不仅会形成一个循环，而且每个循环中数字都是一样的。这一结论是基于有限性原理和确定性操作的重复应用。

```cpp
int ans = 0;
void traceback(int remain, int part, int substract) {
    if (part == 0) {
        if (remain == 0) {
            ans++;
            // cout << remain << "--" << part << "--" << substract << endl;
        }
        return;
    }
    for (int i = substract; i <= remain / part; i++) {
        traceback(remain - i, part - 1, i);
    }
}
//
int main() {
    int n, k;
    cin >> n >> k;
    traceback(n, k, 1);
    cout << ans;
}
```
较为简单的回溯思想
- 叶节点是 `part==0 `，但有些叶节点**需要废弃**，即 `part==0&&remain!=0` 时
- 遍历每一个叶节点
- 每一个**有子节点的中间结点**（能够被分）下的叶节点都必须要是**当前值被分为当前 part 份**的所有结果，不能有遗漏
最容易犯错误的地方是 for 循环中对于 i 的取值范围
```cpp
for (int i = substract; i <= remain / part + remain % part; i++) {
    traceback(remain - i, part - 1, i);
}
```
- 每一个[[题型分类#^nw879f|多叉树]]中节点，子节点数量是变化的，虽然 `remain/part` 会在某个时刻因余数而遗漏掉，但在到达叶节点（最后一次循环时），part 会等于 1，这时候就不会有余数，正好这时也是一种情况。
- 上面这种写法就是认为每一个节点的子节点分支是固定的，并没有考虑到最后 part 会等于 1 这一种情况。
- 由于 `remain / part + remain % part` 有可能大于 remain，会导致本来要 remain 要等于 0 的时候变为负数，这时候 ans 就不会++，所以会有答案错误。并且由于多算了余数，时间会变长（TLE）

```cpp
    if (findPath(root->right, target, path)) return true; // 在右子树中查找
```

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root; // 如果当前节点是 p 或 q，返回当前节点
    TreeNode* left = lowestCommonAncestor(root->left, p, q); // 在左子树中查找
    TreeNode* right = lowestCommonAncestor(root->right, p, q); // 在右子树中查找
    if (left && right) return root; // 如果 p 和 q 分别在左右子树中，返回当前节点
    return left ? left : right; // 返回非空的子树结果
}
```
这种代码比较巧妙，核心思想为：

> 递归要假设当前递归函数能够返回正确的想要的结果，即
> 如果左子树中没有 p 或者 q，返回 nullptr，右子树同理，空结果表示未找到
> 如果 p 和 q 都在左子树中，Left 在调用函数后非空且为 pq 在左子树的**最近公共祖先节点**
> 如果 p 和 q 都在右子树中，right 在调用函数后非空且为 pq 在中右子树的**最近公共祖先节点**

- 如果分开在**当前节点**不同的子树中，则 left 和 right 都会返回非空结果 `if (left && right) return root;` 如果从这一条语句中返回则说明 pq 分开
- 如果只在 pq 只在一个子树中，将会从最后的 return 返回，因这种情况下当前节点另一个递归分支会因没找到返回空
- 这两个判断分支能不能调换顺序，因最后 return 需要前面 if 筛选

##### 7. 两个二叉树最深的叶子结点的最近公共祖先
```cpp
TreeNode* lcaDeepestLeaves(TreeNode* root) {
    return dfs(root).second; // 返回最深叶子节点的最近公共祖先
}

pair<int, TreeNode*> dfs(TreeNode* root) {
    if (!root) return {0, nullptr}; // 空树，返回深度 0 和 nullptr
    auto left = dfs(root->left); // 左子树的结果
    auto right = dfs(root->right); // 右子树的结果
    if (left.first == right.first) { // 如果左右子树的深度相等
        return {left.first + 1, root}; // 返回当前节点
    } else if (left.first > right.first) { // 如果左子树的深度更大
        return {left.first + 1, left.second}; // 返回左子树的结果
    } else { // 如果右子树的深度更大
        return {right.first + 1, right.second}; // 返回右子树的结果
    }
}
```
- `first` 表示当前子树的深度。
- `second` 表示当前子树中最深叶子节点的最近公共祖先。
- “递”过程中每回归一次在当前层数上+1，返回当前节点
- 最关键的在于归的过程，dfs 一直向下遍历直到达到空节点向上回归，每一层“归”时会得到两个信息：当前节点左子树中最深的节点的深度，当前节点右子树中最深的深度，通过比较哪一个更深而使函数返回**左右节点中**最深的节点**相对于当前遍历节点的层数**和它的指针
- 这样在下一次向上归时，返回到上一层的才会是**最深子节点**，因一个节点本身是他的**最近祖先**

```cpp
    int right = dfs(root->right, diameter); // 右子树的深度

    return max(left, right) + 1; // 返回当前树的深度
```

动态规划问题思考方法：
1. 定义子问题 ：
	- 原问题要能由子问题表示：原问题是 “从全部房子中能偷到的最大金额”，将问题的规模缩小，子问题就是 “从 k 个房子中能偷到的最大金额 ”，注意这里**没有说明是从前 k 个房子还是后 k 个房子**，因定义子问题这一步还没有确定顺序
	- 一个子问题的解要能通过其他子问题的解求出。F (k) 可以由 f (k−1) 和 f (k−2) 求出，即“**最优子结构**”。如果定义不出这样的子问题，那么这道题实际上没法用动态规划解。
	- 将子问题推广到最小的情况，即从 1 个房子中偷到的最大金额，直接 return 金额即可
2. 写出子问题的递推关系
	- K 个房子中最后一个房子是 H (k−1)​。
	- 如果不偷这个房子，那么问题就变成在前 k−1 个房子中偷到最大的金额，也就是子问题 f (k−1)。
	- 如果偷这个房子，那么前一个房子 H (k−2) 显然不能偷，其他房子不受影响。那么问题就变成在前 k−2 个房子中偷到的最大的金额。
	- 两种情况中，选择金额较大的一种结果 `f(k)=max{f(k−1)+f(k−2)}`
---
- 还需要注意边界条件（可以也单独做一步 [[#DP#代码随想录]] 的五步法）
- 在写递推关系的时候，要注意写上 k=0 和 k=1 的基本情况：
- 当 k=0 时，没有房子，所以 f (0)=0。
- 当 k=1 时，只有一个房子，偷这个房子即可，所以 f (1)=H (0)
3. 确定 DP 数组的计算顺序
	- DP 数组也可以叫”子问题数组”，因 DP 数组中每一个元素都对应一个子问题。
![[Pasted image 20250317110321.jpg|400]]
fk 对应前 k 个房子的情况，`dp[k]` 依赖 `dp[k-1]` 和 `dp[k-2]`，易得遍历方向**从前向后**
```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
		int n = nums.size();
		if(n==0) return 0;
		vector<int> dp(n+1,0);
		dp[1] = nums[0];
		for(int k = 2;k<=n;k++){
			dp[k] = max(dp[k-1],dp[k-2]+nums[k - 1]);
		}
		return dp[n];
    }
};
```

#### 122. 买卖股票的最佳时机 II
(https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)
做这一题最关键是分析出**局部最优是什么**：
需要获得全局最优 -> price 遍历完后利润最大 -----> 每天的最大利润就是局部最优，将每天的利润累加（没有利润，亏损不要，因有了他们就不是**局部最优**）
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int max_diff = 0;
        for (int i = 1; i < prices.size(); i++) {
            max_diff += prices[i] - prices[i - 1] > 0 ? prices[i] - prices[i - 1] : 0;
        }
        return max_diff;
    }
};
```
也可以通过 dp 做：
1. Dp 数组定义
	`dp[i][j]` 表示到下标为 `i` 的这一天，持股状态为 `j` 时，我们手上拥有的最大现金数。
	- 第一维 i 表示下标为 i 的那一天（ 具有前缀性质，即考虑了之前天数的交易 ）；
	- 第二维 j 表示下标为 i 的那一天是持有股票，还是持有现金。这里 0 表示持有现金（cash），1 表示持有股票（stock）。
2. 状态转移方程：
	- 一般的 dp 所求的值就是 dp 数组的值，这题需要求最后一天获得的最大利润，表示为最后一天的现金 - 第一天的现金。将**每天的现金数**作为这一天的状态，这个状态可以在不同天数之间传递，**并且状态根据这一天股票是否出售和前一天是否入手决定**
	- ![[Pasted image 20250318203644.png]]
	- `dp[i][1] = max(dp[i-1][1], max[i-1][0] - price[i])`，下标为 i 的这一天并且持有股票时手中现金 = 前一天手中持有股票（当天没有出手手中旧股票）和前一天出手了股票并且当天买入新的股票**中最大的**
	- `dp[i][0] = max(dp[i-1][0], max[i-1][1] + price[i])` 同理，标为 i 的这一天没有股票时手中现金 = 前一天同样状态下手中现金和前一天持有股票并且前一天出手**中最大的**
	- 可以发现，状态方程的维度和数量由**一天中符合状态数**决定，这题有两个状态方程原因是持股状态是 bool 值，并且不可能在同一天发生，是时间的分支，需要分情况讨论
3. 确定初始值：
	- `dp[0][0]` 表示**下标为 0**即第一天的现金，第一天无利润，所以 `dp[0][0] = 1`
	- `dp[0][1]` 表示**下标为 0**即第一天有股拍哦，说明第一天买入了，所以 `dp[0][0] = -price[0]`
	- 初始化，第一天只有两种状态，由于递推方程是一个`2*n`的矩阵，并且从左向右遍历一次遍历一列，每次递推需要当前递推位置前一个位置的状态，不许知道第一列的信息才能递推
4. 确定遍历方向
	- 当天的现金由前 1天的现金决定，所以从左到右遍历
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        vector<vector<int>> dp(prices.size() + 1,vector<int>(2));
        dp[0][0] = 0, dp[0][1] = -prices[0];
        for (int i = 1/* 初始化定义完了第1天的所有情况 */; i < prices.size(); i++) {
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
        }
        return dp[prices.size() -1][0];
    }
};
```
同样可以优化空间，状态压缩
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        int cash = 0, pre_cash = cash;
        int hold = -prices[0], pre_hold = hold;
        for (int i = 1; i < prices.size(); i++) {
            cash = max(pre_cash, pre_hold + prices[i]);
            hold = max(pre_hold, pre_cash - prices[i]);

            pre_cash = cash;// 手动
            pre_hold = hold;
        }
        return cash;
    }
};
```
- 这里的空间优化变量名很容易弄混，较为便捷的方法是照着源代码上改，由于每个 dp 方程中，只用到了上一层（i 为层数）的状态信息，又有两个状态方程，所以 4 个变量分别接管 `dp[i][0]`、`dp[i][1]`、`dp[i-1][1]` 和 `dp[i-1][0]` 对照着写就不会出错（就算不好定义变量名都使用 abcd 也是对的）
- 由于数组中当前更新的值会在下一层被当做下一层更新依据，而用 4 个变量不会自动更新要手动
还可以通过回溯算法暴力求解（一般能用 dp 都能用回溯暴力）
类似选或不选，每种状态转变为下一种状态的方法是有限的，多状态复合问题，都可以转化为树形问题然后暴力回溯----> [[#回溯算法]]
![[Pasted image 20250318214945.png]]
- Dp 和暴力回溯有点蕾西，每个节点**当前状态过渡到下一个状态的方案数**是树的横向维度由迭代控制，能改变几次状态是树的深度，由递归决定
- 迭代次数在本题中只有两种，递归方程在每个不同的状态改变方案中是不同的（+- `price[i]` 不太好写代码），所以这里直接用 if-else 代替
- 如果迭代的次数（状态改变方案数）是变化的，就需要**在递归开始时标记状态以改变**，子递归中没有满足要求的情况时，回溯（后悔一步）将标记取消不影响下一个回溯分支（这里状态和回溯遍历的分支没有关系，永远都是 01，所以不需要回溯）
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        vector<array<int, 2>> memo(n, {-1, -1}); // -1 表示还没有计算过
        auto dfs = [&](this auto&& dfs, int i, bool hold) -> int {
            if (i < 0) {
                return hold ? INT_MIN : 0;
            }
            int& res = memo[i][hold]; // 注意这里是引用
            if (res != -1) {
                return res; // 之前计算过
            }
            if (hold) {
                return res = max(dfs(i - 1, true), dfs(i - 1, false) - prices[i]);
            }
            return res = max(dfs(i - 1, false), dfs(i - 1, true) + prices[i]);
        };
        return dfs(n - 1, false);
    }
};
```

```cpp
class Solution {
public:
    int dfs(vector<int>& prices, vector<array<int,2>>& memo, int index, bool is_hold) {
        if (index < 0) return is_hold ? -1e9 : 0;// index最低到0表示第一天
        int& res = memo[index][is_hold];
        if (res != -1) return res; // 记忆化

        // 两个分支分出两种情况
        if (is_hold) {
            return res = max(dfs(prices, memo, index - 1, true), dfs(prices, memo, index - 1, false) - prices[index]);
        }else{
        	return res = max(dfs(prices, memo, index - 1, false), dfs(prices, memo, index - 1, true) + prices[index]);
        }
    }
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        vector<array<int, 2>> memo(n, { -1,-1 });// array 是C风格数组，初始化很快
        return dfs(prices, memo, prices.size() - 1, false);
    }
};
```

## 并查集
基本知识讲解：[【算法与数据结构】—— 并查集-CSDN博客](https://blog.csdn.net/the_zed/article/details/105126583)
并查集是一种**树型的数据结构**，用于处理一些不相交集合的合并及查询问题（即所谓的并、查）。比如说，我们可以用并查集来判断一个森林中有几片树林、某一棵树是否属于某片树林等。
### 基本原理
模板题可以参考[[刷题路线#洛谷#P8654 合根植物]]
并查集主要由一个整型数组 `pre[ ]` 和两个函数 `find()`、`join()` 构成。
数组 `pre[ ]` 记录了每个点的前驱节点是谁，函数 `find(x)` 用于查找指定节点 x 属于哪个集合，函数 ` join(x,y)` 用于合并两个节点 x 和 y 。
#### find 函数-->查找一个连通分量主节点（门派教主）
如何判断一个人属于哪一个门派？--> 根据门派教主是谁区分
如何找到一个门派的教主？-->find 函数用来查找
```cpp
int find(int x)	{				// 查找 x 的教主
	while(pre[x] != x)			// 如果x的上级不是自己（则说明找到的人不是教主）
		x = pre[x];				// x 继续找他的上级，直到找到教主为止
	return x;					// 教主驾到~~~
}
```
#### join 函数 --> 连通分量中加入新的节点（添加门派新人&合并门派）
合并门派方法
```cpp
void join(int x,int y) {                   // 我想让虚竹和周芷若做朋友（功能：将两个节点 x 和 y 合并到一棵树中）
    int fx=find(x), fy=find(y);            // 虚竹的老大是玄慈，芷若MM的老大是灭绝（寻找 x, y 的代表元）
    if(fx != fy)                           // 玄慈和灭绝显然不是同一个人（如果 x 和 y 的代表元不相等）
        pre[fx]=fy;                        // 方丈只好委委屈屈地当了师太的手下啦（则将 x 的代表元设置为 y 的代表元）
}
```

```cpp
int find(int x) {    			// 查找结点 x 的根结点
    if(pre[x] == x) return x;		// 递归出口：x 的上级为 x 本身，即 x 为根结点
    return pre[x] = find(pre[x]);	// 此代码相当于先找到根结点 rootx，然后 pre[x]=rootx
}
```
**缺陷**：如果拿到手的一个图是一个**成品图**（leetcode 的 io 代码评判规则中参数中直接给出），第一次调用 find 查找没有路径压缩效果，因调整路径（将新人（也就是发起 find 的主题）归属于教主）的操作是在 find 函数中执行的。所以**即使第二次 find 操作和第一次 find 查询同样的目标，第二次也会比第一次快**。
如果不是高频重复查找，这一方法和普通遍历**在复杂读上**没有区别。
这种方法适用于**逐步建立图**（ACM iio 类型）时使用，每次输入两个节点的关系就调用一次 `unite` 函数，参考[[刷题路线#洛谷#并查集#P8654 合根植物]]，逐步建立图之后再查查询

一个平衡二（多）叉树可以保证查找效率的同时兼顾操作简单性
比如要合并这两个门派，合并的规则是什么？-->不是加在最末尾，**教主比小兵等级还低**不太现实，而通过权重评价

由于`rank(A) > rank(F)` ，因此令`pre[F]= A`。合并后的图形如下图所示

```cpp
void init(int n) {    				// 初始化函数，对录入的 n 个结点进行初始化
    for(int i = 0; i < n; i++){
        pre[i] = i;     			// 每个结点的上级都是自己
        rank[i] = 1;    			// 每个结点构成的树的高度为 1
    }
}

void union(int x,int y) {
    x=find(x);							// 寻找 x 的代表元
    y=find(y);							// 寻找 y 的代表元
    if(x==y) return ;					// 如果 x和 y 的代表元一致，说明他们共属同一集合，则不需要合并，直接返回；否则，执行下面的逻辑
    if(rank[x]>rank[y]) pre[y]=x;		// 如果 x的高度大于 y，则令 y 的上级为 x
    else {
        if(rank[x]==rank[y]) rank[y]++;	// 如果 x 的高度和 y 的高度相同，则令 y 的高度加1
        pre[x]=y;						// 让 x 的上级为 y
    }
}
```
这种方法总是将小树合并到大树下，保证树的高度最多为 $O(\log n)$ ^[1]，总复杂度：$O((m \times n + k) \cdot \alpha(n))$。
注意，union 函数逻辑不能将 else 中逻辑拆分为：
```cpp
void unite(int x, int y) {
    int root_x = find_root(x);

        return;
    if (node_rank[root_x] > node_rank[root_y]) {
        pre[root_y] = root_x;
    }else if(node_rank[root_x] == node_rank[root_y]){
        node_rank[root_y]++;
    }else{
    	// node_rank[root_y]++;
        pre[root_x] = root_y;
    }
}
```

```cpp
int factorial(int n) {

        return 1;
```

## 树状数组
本质：一种支持 **单点修改** 和 **区间查询** 的，代码量小的**数据结构**。
特点：
- 树状数组能解决的问题是**线段树能解决的问题的子集**：树状数组能做的，线段树一定能做；线段树能做的，树状数组不一定可以。然而，树状数组的代码要远比线段树短，时间效率常数也更小，因此仍有学习价值
- 在差分数组和辅助数组的帮助下，树状数组还可解决更强的 **区间加单点值** 和 **区间加区间和** 问题

	- 结合律：(𝑥 ∘𝑦) ∘𝑧 =𝑥 ∘(𝑦 ∘𝑧)，其中 ∘ 是一个二元运算符。
	- 可差分：具有逆运算的运算，即已知 𝑥 ∘𝑦 和 𝑥 可以求出 𝑦
