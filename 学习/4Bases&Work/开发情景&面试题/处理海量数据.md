## 卡时间卡内存
### 40 亿 qq 号去重
位图法：
```cpp
class Bitmap {
private:
    bitset<4000000000> bitArray; //假设qq号固定10位，并且从0开始依次+1
public:
    void add(int value) {
        bitArray[value] = 1;
    }
    bool contains(int value) {
        return bitArray[value] == 1;
    }
};
```
每个位只有 1 bit，40 亿数据约 0.5 G 是可以接受的，只记录 qq 号是否存在，并不记录号码信息
布隆过滤器：
```cpp
class BloomFilter {
private:
    bitset<1000000> bitArray; // 位数组，大小可根据内存调整
    vector<function<size_t(int)>> hashFunctions; // 哈希函数列表

public:
    BloomFilter() {
        // 初始化哈希函数
        hashFunctions.push_back([](int x) { return hash<int>()(x) % 1000000; });
        hashFunctions.push_back([](int x) { return (x * 31) % 1000000; });
        hashFunctions.push_back([](int x) { return (x * 17) % 1000000; });
    }

    // 添加元素
    void add(int value) {
        for (const auto& hashFunc : hashFunctions) {
            size_t index = hashFunc(value);
            bitArray[index] = 1;
        }
    }

    // 检查元素是否存在
    bool contains(int value) {
        for (const auto& hashFunc : hashFunctions) {
            size_t index = hashFunc(value);
            if (bitArray[index] == 0) {
                return false; // 一定不存在
            }
        }
        return true; // 可能存在
    }
};
```
- 通过多个哈希函数将元素映射到一个位数组中，并将对应位置设置为 1。查询时，如果所有哈希函数对应的位都为 1，则认为元素可能存在；否则，元素一定不存在。
- 哈希函数的映射规则应该尽可能分散并且不易冲突（这里使用质数取余法使容器中的 1 分布尽量分散，并且质数越大越分散，但是空间消耗指数上升）
- 可以通过调整哈希函数和 bitset 容量来调整准确率
---
**位数组**：空间利用率较高，查询速度快，且没有误判。但它的缺点是空间利用率仍有提升空间，对于更大的数据量，可能会占用更多内存。
**布隆过滤器**：空间利用率极高，查询速度极快（每次查询只需要查询哈希函数数量个位置是否被标记为 1 即可），适合处理海量数据。但它的缺点是存在误判率，虽然可以通过调整参数来降低误判率，但无法完全避免。
