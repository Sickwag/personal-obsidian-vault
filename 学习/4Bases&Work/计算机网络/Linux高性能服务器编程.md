#### 1.1.1 数据链路层
数据链路层两个常用的协议是ARP 和 RARP，

- ARP：网络层使用 IP 地址寻找一台机器，网络层必须先将目标机器的IP地址转化成其物理地址，才能使用数据链路层提供的服务
- RARP：网络上的某些无盘工作站。因为缺乏存储设备，无盘工作站无法记住自己的IP地址，但它们可以利用网卡上的物理地址来向网络管理者（服务器或网络管理软件）查询自身的IP地址。运行RARP服务的网络管理者通常存有该网络上所有机器的物理地址到IP地址的映射
#### 1.1.2 网络层
IP 协议：
网络层最核心的协议是IP协议（Internet Protocol，因特网协议）。IP协议根据数据包的目的IP地址来决定如何投递它。
ICMP 协议：
是IP协议的重要补充，主要用于检测网络连接。
