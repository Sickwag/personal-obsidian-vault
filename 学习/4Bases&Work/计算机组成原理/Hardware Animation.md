## 什么是随机存取存储器
RAM（random access）存储在主办的DIMS（dual inline memory Module）模块中的硬件，有两个针脚部分，有168  184  240  288四种针脚数量规格

- CPU需要处理的数据首先存储在硬盘中，然后在需要时被加载到RAM中，RAM中的数据可以被CPU直接读取
- 当RAM太小时，部分数据无法一次性全部加载进CPU，只能先放在硬盘中。在需要部分村除杂硬盘中数据时，RAM再吧数据放回到硬盘，然后读取新的数据进来。**这一过程会降低计算机速度** 

#### RAM的类型
- DRAM（dynamic RAM）：需要恒定电源供电，因为DRAM的结构是用电容器存储数据，电容器不能长时间保持电量，必须保证储存的电能动态刷新以保存数据。所有的数据变化不按照系统时间校准，无法准确计时
- SDRAM（synchronous dynamic RAM）：同样使用电容存储结构。同步系统时间变化数据，这导致了他的速度比SDRAM更快。

#### RAM的速率计算
- RAM的位数指的是在单位时间（时钟时间周期内）的电脑数据传输位数。旧版的内存可能使用的是SIM（模拟内存）存储格式，但是一次只能传输32为数据，DIMS一般是64位数据
- 首先看RAM的频率，在内存中的术语是速度（speed）单位为MHz千兆赫兹。
- 再看RAM的总线（wide bus）宽度，如果是64位RAM就有8bit宽度。
- RAM的读取速度就是**100 * 8=800MB/s**

#### 新兴内存技术
- **DDR技术（double data rate）**
顾名思义，DDR在每个时钟周期发送的数据是非DDR的两倍![Pasted image 20240330124525.png](Pasted%20image%2020240330124525.png)
DDR利用了数据波段的波峰和波谷两段发送数据
![Pasted image 20240330124721.png](Pasted%20image%2020240330124721.png)
标签上说明了内存的速度
- **DDR2技术**
通过拓展总线宽度，使得DDR2拥有两倍于DDR的速度，风少的电量
![Pasted image 20240330124930.png](Pasted%20image%2020240330124930.png)
- **DDR3**
是DDR2内存速度的两倍，使用更少的电量
同样的240个针脚，但是针脚缺口位置不一样![Pasted image 20240330125112.png](Pasted%20image%2020240330125112.png)
- DDR4
更快速度，消耗更少电量，拥有288个针脚
![Pasted image 20240330125231.png](Pasted%20image%2020240330125231.png)

#### 其他
- 有些RAM中会集成ECC（error coding code）用来检测故障
- 观察内存模块的存储芯片数量可以改看出有没有集成（一般是8个芯片，9个就说明集成了ECC）
- ECC并不是一定需要的，也不是装了ECC的内存更稳定，由于技术的进步，使得内存总很少出现错误，只有在一些极其重要的服务器中，需要安装ECC防止数据错误使服务器宕机

## 双频段路由器
频段是无线数据在设备之间的传输方式
![Pasted image 20240330121156.png](Pasted%20image%2020240330121156.png)单带路由器只能传输其中的一个波段（band）
许多设备（如微波炉，手机，路由器）一般都使用2.4GHZ，为了**防止2.4Ghz频段过于拥挤而影响信号接收**，新设备一般支持5GHZ频段来降低 干扰

### 降低干扰的方法
- 更换频道（channel）
2.4GHZ有11个频道可以选择，其中有3个信号频道不重叠，这是最稳定的三个频道
![Pasted image 20240330121744.png](Pasted%20image%2020240330121744.png)
5GHZ有两个不重叠频道，25个频道

### 两者之间的不同
- 2.4Ghz频段的传输速度比5GHz要低，但是覆盖范围广，在信号源很多时易受到干扰。
- 5Ghz相反，因为高频率电波的穿透力更强

## 什么是子网（subnets）和vlans
**共性**
用于将网络分解为更小的网络（提高安全性，性能和易管理性）
#### 子网
**子网是通过路由器创建的，小型的局域网是有多个连接在一个路由器上的几台计算机组成的**
- 当局域网中的计算机想要与其他计算机通信时需要连接在同一个“交换机（Switch，不是路由器）”上![Pasted image 20240330164640.png](Pasted%20image%2020240330164640.png)
- 类似于集线器，当一个计算机想要向外通信，发送广播时所有计算机都会受到广播，所以一旦计算机的数量多起来，就会造成数据拥挤和资源浪费![Pasted image 20240330164819.png](Pasted%20image%2020240330164819.png)
- 子网本质是**由路由器隔开的不同广播域**组成
- 每个子网都有属于自己的广播域，广播不会穿过路由器传播![Pasted image 20240330165110.png](Pasted%20image%2020240330165110.png)
企业间的各个部门需要保证数据安全性，数据只在各个部门之内流动，就需要建立子网

这种交换机可以配置网络流量，可以看做是多个交换机的组合集成，这种集成互不干扰，每个集成进来的交换机的接口数量和流量都可以通过控制VLAN控制。![Pasted image 20240330165713.png](Pasted%20image%2020240330165713.png)

## 集线器（hub）交换机（Switch）路由器（router）
处理数据的方式不同
#### 集线器
作用是将所有数据汇总到一起
- 现在的集线器是不智能的
- 不过滤任何数据
- 不包含任何数据来源和数据发送地址的信息
工作原理：当集线器的一个端口收到数据时，他将把这个数据发送到所有其他端口，**一入多出**没有任何数据针对性，安全性差，造成了不必要的流量浪费
#### 交换机
相对于集线器，交换机可以学习连接到他的设备的物理地址，由于他的数据开关是智能的。所有的地址数据（Mac地址）存储在它的表中。
交换机在收到数据之后查看mac地址和匹配端口列表，找到匹配的端口并发送数据

>集线器只检测所有设备与他的物理链接
>交换机的开关可以检测连接到他的特定设备，还能够识别并保存mac地址传输数据

#### 路由器
路由器可以使用在需要对外交换数据的网络中，**routers is a device that routes or forwards date from one to another base on their IP adress.**
路由器识别出为相应端口准备的数据并接受它，本质上是网络的网关
![Pasted image 20240329220318.png](Pasted%20image%2020240329220318.png)

#### 建立内网
