# 环境变量是什么
参考教程：[『教程』什么是环境变量_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1w741147G9/?spm_id_from=333.337.search-card.all.click&vd_source=876be08bc9c030f4a9ea1fb97e0d0342)
**定义：** 环境变量是在操作系统中一个具有特定名字的对象，它包合了一个或者多个应用程序所将使用到的信息。

环境变量的主要作用只有：*指明操作系统的重要目录在哪里，使用运行窗口时运行的程序名会在环境变量的 Path 路径中查找并运行*

用户变量和系统变量主要区别在作用范围

## 事实
- SystemRoot 是 windows 中的一个特殊环境变量名，cmd 中运行 `%SystemRoot%` 会打开系统目录（一般在 C 盘的 Windows 文件夹中）
- 输入 cmd 打开命令提示符
