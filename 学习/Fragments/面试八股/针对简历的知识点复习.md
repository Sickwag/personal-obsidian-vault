### 行业最佳实践
模板元编程实现 Pair 和 for_each 支持
```cpp
// std::pair的简单实现
template <typename First, typename Second>
class Pair {
  public:
	Pair() = default;
	Pair(const First& f, const Second& s)
		: first_(f)
		, second_(s) {}
	Pair(First&& f, Second&& s)
		: first_(std::move(f))
		, second_(std::move(s)) {}

	bool operator==(const Pair& other) const { return other.first_ == this->first_ && other.second_ == this->second_; }

	bool operator<(const Pair& other) const {
		return this->first_ < other.first_;	 // std::pair 只需要写到这里即可
		// return this->first_ < other.first_ || (!(other.first_) && this->second_ < other.second_);
	}

	operator std::pair<First, Second>() const { return std::make_pair<First, Second>(first_, second_); }

	First  first_;
	Second second_;
};

template <typename First, typename Second>
Pair<First, Second> make_pair(First&& f, Second&& s) {
    return Pair<First, Second>(std::forward<First>(f), std::forward<Second>(s));
}

template <typename ElemType, size_t N>
class MinForeach {
  public:
	MinForeach(std::initializer_list<ElemType> init) { std::copy(init.begin(), init.end(), data_); }
	ElemType* begin() { return data_; }
	ElemType* end() { return data_ + N; }

  private:
	ElemType data_[N];
};

int main() {
	MinForeach<Pair<int, std::string>, 10> mf = {
		{ 0, "000" },
		  { 1, "111" },
		{ 2, "222" },
		  { 3, "333" },
		{ 4, "444" },
		{ 5, "555" },
		  { 6, "666" },
		{ 7, "777" },
		  { 8, "888" },
		{ 9, "999" }
	};
	for(const auto& item : mf) {
		std::cout << item.first_ << " " << item.second_ << std::endl;
	}
}
```
使用完美转发并将运算符重载函数设置为常函数是**不强制但是已成为行业最佳实践**
- 为什么 Pair 的万能引用类型参数的构造函数就需要使用 `std::move()`来把参数通过移动语义赋值到变量中？

> [!note]
> 因为
> ```cpp
> Pair(First&& f, Second&& s)
>     : first_(f)
>     , second_(s) {}
> ```
> 中，f和s虽然是万能引用对象，但他们本身有名字，所以是左值，这里使用 `std::move()` 减少拷贝开销
- 为什么重载 Pair 的 `==` 和 `<`符号时，参数类型是 const Pair&？这是 C++语法规定的吗？
> [!note]
> 这只是最佳实践，也可以不这样

### 类型运算符
```cpp
operator std::pair<First, Second>() const {
    return std::make_pair(first, second);
}
```
C++中的类型转换：
- 如果有 A，B 两种类，要允许 A->B 的转化，有两种方法：
	- 构造函数转化，定义 `B::B(const A& a)` ，注意这只能允许 A->B
	- 定义 `A::operator B()` 或者 `A::operator=` 类型转换重载
	- 定义模板类转换 `template<typename T> operator T(){return static_cast<T>(value_);}`
- 并且这只是单向的，只能允许 A->B，且**三种方式都会在 `{}` 初始化，`=` 赋值，`()` 方式下触发**
> [!note]
> 这是在允许 Pair->std::pair 的**隐式**转化，这种写法叫做*类型转换运算符*

## 基本 STL 算法
### 一、不修改序列的算法
#### 1. 查找算法
```cpp
// find - 查找元素
auto it = std::find(vec.begin(), vec.end(), 42);
// find_if - 条件查找
auto it = std::find_if(vec.begin(), vec.end(), 
                       [](int x){ return x > 10; });
// count - 计数
int cnt = std::count(vec.begin(), vec.end(), 42);
// count_if - 条件计数
int cnt = std::count_if(vec.begin(), vec.end(),
                       [](int x){ return x % 2 == 0; });
// binary_search - 二分查找（需有序）
bool found = std::binary_search(vec.begin(), vec.end(), 42);
// lower_bound/upper_bound - 边界查找
auto lb = std::lower_bound(vec.begin(), vec.end(), 42);
auto ub = std::upper_bound(vec.begin(), vec.end(), 42);
```
#### 2. 检查算法
```cpp
// all_of - 所有元素满足条件
bool all_even = std::all_of(vec.begin(), vec.end(),
                           [](int x){ return x % 2 == 0; });
// any_of - 任意元素满足条件
bool has_negative = std::any_of(vec.begin(), vec.end(),
                               [](int x){ return x < 0; });
// none_of - 没有元素满足条件
bool no_zero = std::none_of(vec.begin(), vec.end(),
                           [](int x){ return x == 0; });
```
#### 3. 比较算法
```cpp
// equal - 序列相等
bool same = std::equal(vec1.begin(), vec1.end(), vec2.begin());
// mismatch - 查找第一个不同点
auto [it1, it2] = std::mismatch(vec1.begin(), vec1.end(), vec2.begin());
// lexicographical_compare - 字典序比较
bool smaller = std::lexicographical_compare(
    vec1.begin(), vec1.end(), 
    vec2.begin(), vec2.end());
```
### 二、修改序列的算法
#### 1. 拷贝/移动算法
```cpp
// copy - 复制

// copy_if - 条件复制
std::copy_if(src.begin(), src.end(), dest.begin(),
            [](int x){ return x > 0; });
// copy_n - 复制n个元素
std::copy_n(src.begin(), 5, dest.begin());
// move - 移动元素
std::move(src.begin(), src.end(), dest.begin());
// transform - 转换每个元素
std::transform(src.begin(), src.end(), dest.begin(),
               [](int x){ return x * 2; });
// transform - 双输入转换
std::transform(src1.begin(), src1.end(), src2.begin(), dest.begin(),
              [](int a, int b){ return a + b; });
```
#### 2. 填充/生成算法
```cpp
// fill - 填充值
std::fill(vec.begin(), vec.end(), 42);
// fill_n - 填充n个元素
std::fill_n(vec.begin(), 5, 42);
// generate - 使用生成器
std::generate(vec.begin(), vec.end(), 
              [](){ static int i = 0; return i++; });
// generate_n - 生成n个元素
std::generate_n(std::back_inserter(vec), 10,
                [](){ static int i = 0; return i++; });
// iota - 生成递增序列
std::iota(vec.begin(), vec.end(), 0);  // 0, 1, 2, 3...
```
#### 3. 交换算法
```cpp
// swap - 交换两个元素
std::swap(a, b);
// swap_ranges - 交换两个范围
std::swap_ranges(vec1.begin(), vec1.end(), vec2.begin());
// iter_swap - 交换迭代器指向的元素
std::iter_swap(it1, it2);
```
### 三、重新排列算法
#### 1. 排序算法
```cpp

std::nth_element(vec.begin(), middle, vec.end());
```
#### 2. 划分算法

```cpp
// stable_partition - 稳定分区
```

#### 3. 旋转/反转算法

### 总结：最常用的算法
按使用频率排序：
1. **sort** - 排序
2. **find/find_if** - 查找
3. **copy/copy_if** - 复制
4. **transform** - 转换
5. **remove/remove_if + erase** - 删除
6. **count/count_if** - 计数
7. **accumulate** - 累加
8. **for_each** - 遍历
9. **fill/generate** - 填充/生成
10. **partition** - 分区
**核心技巧**：大部分算法都遵循"输入范围-输出迭代器-谓词/操作"的模式，掌握这个模式就能快速学会使用任何 STL 算法。

# Boost 单元测试
## 基本用法
### 测试用例/套件/模块/装饰器
先要在测试模块（有测试代码的文件）中
```cpp
#define BOOST_TEST_MODULE 模块名称
#include <boost/test/unit_test.hpp>
```
测试组件的从属关系是：模块（MODULE）>套件（SUITE）>用例（CASE）>语句（CHECK_XXX）
每个上级可以包含多个下级
```cpp
BOOST_AUTO_TEST_SUITE(string_utils_tests) // 开始套件测试，包含end之前的case
BOOST_AUTO_TEST_CASE(str2double_test) {
    BOOST_CHECK_CLOSE(str2double("3.14159"), 3.14159, 0.0001); // 结果误差
    BOOST_CHECK_THROW(str2double("not_a_number"), std::invalid_argument); // 结果异常
    BOOST_CHECK_EQUAL(arr->get<std::string>(0), "hello\nworld"); // 结果断言
    BOOST_TEST(expression) // expression必须要是bool类型的
}
BOOST_AUTO_TEST_SUITE_END()
```
装饰器一般用于**套件/用例级别**
```cpp
#define BOOST_TEST_MODULE decorator_02
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

BOOST_AUTO_TEST_SUITE(suite1, * utf::label("trivial")) // 通过*引入
BOOST_AUTO_TEST_CASE(test_case1) {
	BOOST_TEST(true);
}

BOOST_AUTO_TEST_CASE(test_case2) {
	BOOST_TEST(1 == 1);
}
BOOST_AUTO_TEST_SUITE_END()
```
引入装饰器的作用是运行测试程序时可以之运行具有某些装饰（依据lable 区分）的测试套件
```bash
> decorator_02 --run_test=@trivial
Running 2 test cases...

*** No errors detected
```
显式宏 [`BOOST_TEST_DECORATOR`](https://boost.ac.cn/doc/libs/latest/libs/test/doc/html/boost_test/utf_reference/test_org_reference/test_org_boost_test_decorator.html "BOOST_TEST_DECORATOR") 指示其装饰器集将应用于紧随声明之后的测试单元或_测试用例序列
```cpp
#define BOOST_TEST_MODULE decorator_00
#include <boost/test/included/unit_test.hpp>
#include <boost/test/data/test_case.hpp>

namespace utf  = boost::unit_test;
namespace data = boost::unit_test::data;

BOOST_TEST_DECORATOR(* utf::description("with description"))
BOOST_DATA_TEST_CASE(test_1, data::xrange(4)) {
    BOOST_TEST(sample >= 0);
}
```
输出：
```bash
> decorator_00 --list_content
test_1*: with description
test_1*: with description
test_1*: with description
test_1*: with description
```
### 测试夹具
一个测试用例夹具是被测试用例使用的夹具：
- 夹具的 `setup` 在测试用例执行前被调用
- 夹具的 `teardown` 在测试用例执行完毕后被调用
- 无论其执行状态如何
默认夹具是一个类/结构体，构造函数为 `setup`，析构为 `teardown`，也可以手动设置 `setup()/teardown()` 函数（可以在类内也可以类外，添加夹具绑定的时候提供对应的指针即可）。夹具**一般用于用例/套件**级别
为用例和套件引入夹具都有两种方式：
1. 通过装饰器引入：不允许访问夹具类成员，但提供了更小粒度的定制化，允许一个用例/套件绑定多个夹具
	- 用例：在 `BOOST_AUTO_TEST_CASE(用例名称， 装饰器)` 装饰器位置通过 `*utf::fixture<夹具类>(std::string(夹具名称))` 引入，
	- 套件：`BOOST_AUTO_TEST_SUITE(suite1, * tf::fixture<Fx>(std::string("FX"))) ......测试用例...... BOOST_AUTO_TEST_SUITE_END()` 这种方式只会在套件上加夹具
2. 通过对应宏引入：这允许访问夹具类的成员（public & protect）
	- 用例：`BOOST_FIXTURE_TEST_CASE(用例名称， 夹具类)`，效果和通过装饰器一样
	- 套件：`BOOST_FIXTURE_TEST_SUITE(套件名称, 夹具类)`，注意这会导致套件内所有用例都加上一套相同的夹具
```cpp
#define BOOST_TEST_MODULE decorator_12
#include <boost/test/included/unit_test.hpp>
namespace utf = boost::unit_test;

struct Fx {
	std::string s;
	Fx(std::string s = "")
		: s(s) {
		BOOST_TEST_MESSAGE("set up " << s);
	}
	~Fx() { BOOST_TEST_MESSAGE("tear down " << s); }
};

void setup() { BOOST_TEST_MESSAGE("set up fun"); } // 自定义夹具setup
void teardown() { BOOST_TEST_MESSAGE("tear down fun"); } // 自定义夹具teardown

BOOST_AUTO_TEST_SUITE(suite1,  // 套件的夹具setup会先于用例的setup运行
	* utf::fixture<Fx>(std::string("FX"))	// 1.先运行FX::setup
	* utf::fixture<Fx>(std::string("FX2"))	// 2. 后运行FX2::setup
)

BOOST_AUTO_TEST_CASE(test1, *utf::fixture(&setup, &teardown)) {	// 提供对应指针
	BOOST_TEST_MESSAGE("running test1"); // 3. 运行用例的夹具::setup
	BOOST_TEST(true);
} // 4. 结束时运行用例夹具::teardown

BOOST_AUTO_TEST_CASE(test2) {
	BOOST_TEST_MESSAGE("running test2");
	BOOST_TEST(true);
}

BOOST_AUTO_TEST_SUITE_END() // 结束套件之前调用夹具Fx2::teardown -> Fx::teardown
//////////////第二个测试程序////////////////////////
struct F {
	F()
		: i(0) {
		BOOST_TEST_MESSAGE("setup fixture");
	}
	~F() { BOOST_TEST_MESSAGE("teardown fixture"); }

	int i;
};

BOOST_FIXTURE_TEST_CASE(test_case1, F) {
	BOOST_TEST(i == 1);
	++i;
}

BOOST_FIXTURE_TEST_CASE(test_case2, F) { BOOST_CHECK_EQUAL(i, 1); }
BOOST_AUTO_TEST_CASE(test_case3) { BOOST_TEST(true); }
```

```bash
tear down fun
running test2
tear down FX2	# 注意两者顺序
```

_单元测试框架_ 提供了几种定义测试用例夹具的方式，每种方式都有其特性

- 为单个测试用例声明一个夹具，允许测试用例访问夹具的成员，
- 为单个测试用例声明一个或多个夹具，但不访问成员，并提供灵活的接口，
- 为由子树定义的测试用例组声明一个夹具，并允许访问夹具的成员。
以下两种方法可用于声明附加到特定测试用例的夹具
- 使用宏 [`BOOST_FIXTURE_TEST_CASE`](https://boost.ac.cn/doc/libs/latest/libs/test/doc/html/boost_test/utf_reference/test_org_reference/test_org_boost_test_case_fixture.html "BOOST_FIXTURE_TEST_CASE") 代替 [`BOOST_AUTO_TEST_CASE`](https://boost.ac.cn/doc/libs/latest/libs/test/doc/html/boost_test/utf_reference/test_org_reference/test_org_boost_auto_test_case.html "BOOST_AUTO_TEST_CASE")，允许访问夹具成员
- 使用装饰器 [`fixture`](https://boost.ac.cn/doc/libs/latest/libs/test/doc/html/boost_test/utf_reference/test_org_reference/decorator_fixture.html "fixture (decorator)")，不允许访问成员，但允许为单个测试用例定义多个夹具。
