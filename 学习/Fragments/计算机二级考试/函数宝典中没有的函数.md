- 三个LOOKUP函数

**VLOOKUP函数**

[VLOOKUP函数在Excel中用于在数据表的第一列中查找特定值，并返回该值所在行的其他列中值](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)[2](https://support.microsoft.com/zh-cn/office/vlookup-%E5%87%BD%E6%95%B0-0bbc8083-26fe-4963-8ab8-93a18ad188a1)。函数的基本结构如下：

```Plain
=VLOOKUP(查找值, 数据表, 列序数, [匹配条件])
```

- [**查找值**](https://zhuanlan.zhihu.com/p/387830213)[：要查找的值，必须位于数据表的第一列](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)。
- [**数据表**](https://zhuanlan.zhihu.com/p/387830213)[：查找的区域](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)。
- [**列序数**](https://zhuanlan.zhihu.com/p/387830213)[：返回数据表中第几列的数据](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)。
- [**匹配条件**](https://zhuanlan.zhihu.com/p/387830213)[：可选，如果为0（TRUE）表示精确查找；1（False）或省略表示模糊查找](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)。

[例如，假设我们要从下边列表中找到 “aaa”的成绩，可以编写函数](https://zhuanlan.zhihu.com/p/387830213) [`=VLOOKUP(G2,B2:D10,3,TRUE)`](https://zhuanlan.zhihu.com/p/387830213)[1](https://zhuanlan.zhihu.com/p/387830213)。

**XLOOKUP函数**

[XLOOKUP函数是Excel中一个新函数，它可以在任何方向工作，并默认返回精确匹配项](https://support.microsoft.com/zh-cn/office/xlookup-%E5%87%BD%E6%95%B0-b7fd680e-6d10-43e6-84f9-88eae8bf5929)[3](https://support.microsoft.com/zh-cn/office/xlookup-%E5%87%BD%E6%95%B0-b7fd680e-6d10-43e6-84f9-88eae8bf5929)。函数的基本结构如下：

```Plain
=XLOOKUP(查找值, 查找范围, 结果范围, [找不到时显示的值], [匹配方式], [查询模式])
```

- [**查找值**](https://zhuanlan.zhihu.com/p/387830213)[：要查找的值](https://zhuanlan.zhihu.com/p/387830213)[4](https://zhuanlan.zhihu.com/p/427711247)。
- [**查找范围**](https://zhuanlan.zhihu.com/p/387830213)[：查找的区域](https://zhuanlan.zhihu.com/p/387830213)[4](https://zhuanlan.zhihu.com/p/427711247)。
- [**结果范围**](https://zhuanlan.zhihu.com/p/387830213)[：返回的区域](https://zhuanlan.zhihu.com/p/387830213)[4](https://zhuanlan.zhihu.com/p/427711247)。
- [**找不到时显示的值**](https://zhuanlan.zhihu.com/p/387830213)[：可选，如果查找不到值时显示的内容](https://zhuanlan.zhihu.com/p/387830213)[4](https://zhuanlan.zhihu.com/p/427711247)。
- [**匹配方式**](https://zhuanlan.zhihu.com/p/427711247)[：可选，0或者省略是精确匹配，-1是精确匹配或下一个较小的项，1是精确匹配或下一个较大的项，2是通配符匹配](https://zhuanlan.zhihu.com/p/427711247)[4](https://zhuanlan.zhihu.com/p/427711247)。
- [**查询模式**](https://zhuanlan.zhihu.com/p/427711247)[：可选，1是从上向下，默认的也是这种方式，-1是从下向上，2是执行依赖于lookup_array按升序排序的二进制搜索，-2是执行依赖于lookup_array按降序排序的二进制搜索](https://zhuanlan.zhihu.com/p/427711247)[4](https://zhuanlan.zhihu.com/p/427711247)。

[例如，按照姓名匹配入职日期，公式为](https://zhuanlan.zhihu.com/p/387830213)[`=XLOOKUP(G2,B:B,C:C)`](https://zhuanlan.zhihu.com/p/387830213)[4](https://zhuanlan.zhihu.com/p/427711247)。

**HLOOKUP函数**

HLOOKUP函数在Excel中用于在数据表的首行查找特定值，并返回该值所在列的其他行中值。函数的基本结构如下：

```Plain
=HLOOKUP(查找值, 数据表, 行序数, [匹配条件])
```

- **查找值**：要查找的值。
- **数据表**：查找的区域。
- **行序数**：返回数据表中第几行的数据。
- **匹配条件**：可选，如果为0（TRUE）表示精确查找；1（False）或省略表示模糊查找。

例如，假设我们有一个员工表，如下所示：

| 员工ID | E001 | E002 | E003 |
| ---- | ---- | ---- | ---- |
| 姓名   | 张三   | 李四   | 王五   |
|工资|5000|6000|5500|

我们想要查找员工ID为E002的员工的工资，可以使用以下公式：

```Plain
=HLOOKUP("E002", A1:D3, 3, FALSE)
```

这将返回6000，这是李四的工资。
