## Qt 缺少 mysql 驱动导致无法连接 mysql
教程参考：[Qt 如何连接 MySQL 数据库 | bachzart's Blog](https://bachzart.github.io/2025/04/14/Qt-%E5%A6%82%E4%BD%95%E8%BF%9E%E6%8E%A5-MySQL-%E6%95%B0%E6%8D%AE%E5%BA%93/)
缺失驱动文件下载
旧版本（5.9~5.12）qt 可以使用 [GitCode](https://gitcode.com/Universal-Tool/d64096/?utm_source=article_gitcode_universal&index=top&type=card&&uuid_tt_dd=10_37518426970-1728006576920-345973&isLogin=1&from_id=147300616&from_link=fb97886593d0d659e665e045cc1060f6) 这个链接下载驱动
qt 6 新版本驱动 [Releases · thecodemonkey86/qt_mysql_driver](https://github.com/thecodemonkey86/qt_mysql_driver/releases) 下载对应版本
- 将 MySQL 安装路径 `C:\Program Files\MySQL\MySQL Server 8.0\lib` 目录下的 `libmysql.dll` 和 `libmysql.lib` 这两个文件放到 Qt 安装目录 `D:\Qt\Qt5.14.2\5.14.2\mingw73_64\bin` 目录下。
- 将 `qsqlmysql.dll` 和 `qsqlmysqld.dll` 放到 ` D:\Qt\Qt5.14.2\5.14.2\mingw73_64\plugins\sqldrivers ` 这个目录中
- 注意 qt 的版本和**位数**一样重要，64 位的电脑上**有可能**能够运行 32 位的 qsqlmysql. dll，但是最好下载对应版本的。
可以使用下面的方法查看 qt 支持现在内置什么驱动：
```cpp
qDebug()<<"available drivers:";
QStringList drivers = QSqlDatabase::drivers();
foreach(QString driver, drivers)
    qDebug()<<driver;
```
当出现内容为
```bash
available drivers:
"QSQLITE"
"QMIMER"
"QMARIADB"
"QMYSQL"
"QODBC"
"QPSQL"
```
就说明已经能够通过 qt 连接上 mysql 了。
