# 基本认识
## 模板基本使用
参考：[后几章节--模板基本知识](https://www.yuque.com/lianlianfengchen-cvvh2/zack/xm79tzu27moll8r9)
### 简单类模板
简单 pair 类：
```cpp
template <typename T, typename U>
class Pair {
public:
	T first;
	U second;
	
	Pair(T a, U b) : first(a), second(b) {}
	
	void print() const {
	    std::cout << "Pair: " << first << ", " << second << std::endl;
	}
};
```
### 模板类型参数
分为类型参数和非类型参数
```cpp
// 类型参数
template <typename T>
class MyClass {
public:
	T data;
};
// 非类型参数
template <typename T, int N>
class FixedArray {
public:
	T data[N];
};
```
非类型参数作为一种**数据**传入，帮助其他类型的构建。
```cpp
// 模板模板类型参数
template <template <typename, typename> class Container, typename T>
class ContainerPrinter {
public:
	void print(const Container<T, std::allocator<T>>& container) {
	    for(const auto& elem : container)
	        std::cout << elem << " ";
	    std::cout << std::endl;
	}
};
// 用法
std::vector<int> vec{1,2,3,4,5};
ContainerPrinter<std::vector, int> vecPrinter;
vecPrinter.print(vec); // 输出：1 2 3 4 5
// vetor定义
template<
    class T,
	class Allocator = std::allocator<T>
> class vector;
```
ContainerPrinter **模板类**定义表示这个模板只接受 2 个模板参数，第一个模板参数的类型必须是**能够接受两个模板类型参数的模板类型**，第二个是一个类型
### 模板特化
模板类支持**全特化（Full Specialization）和偏特化（Partial Specialization）**，但需要注意的是，**函数模板不支持偏特化**，只能进行全特化。
#### 类模板全特化
全特化是针对模板参数的**完全特定类型**组合。它提供了模板的一个特定版本，需要定义所有模板参数的特化类型
```cpp
// 通用类模板
template <typename T>
class Printer {
public:
	void print(const T& value) {
	    std::cout << "General Printer: " << value << std::endl;
	}
};

// 类模板全特化
template <>
class Printer<std::string> {
public:
	void print(const std::string& value) {
	    std::cout << "String Printer: " << value << std::endl;
	}
};

int main() {
    Printer<int> intPrinter;
    intPrinter.print(100); // 输出：General Printer: 100

    Printer<std::string> stringPrinter;
    stringPrinter.print("Hello, World!"); // 输出：String Printer: Hello, World!

    return 0;
}
```
- `template<...>` 中内容可以理解为模板类实例化参数列表，`class<...>` 中内容可以理解为模板实例化参数列表默认值（模板实参列表，用于指定 `template<>` 中的具体内容），` class<std::string>` 表示实例化时必须要传入类型为 ` std::string ` 类型的参数。
	- 全特化所有模板参数都是固定的，那么没有必要写在 ` template<>` 尖括号中
	- 偏特化只是部分参数模板固定，所以 `template<>` 和 `class<>` 中都需要说明，而 `class<>` 中填入内容相当于在实例化过程中填入的内容，**是具体的类型而不是 `T，U` 这种代词**
- 两个模板同时存在时，实例化 `Printer<std::string>` 时，编译器选择全特化版本而非通用模板。
#### 类模板偏特化
偏特化允许模板**对部分参数进行特定类型的处理**，同时保持其他参数的通用性。对于**类模板**而言，可以针对模板参数的某些特性进行偏特化；对于**函数模板**，则仅支持全特化，不支持偏特化

最常用的场景是：通用的模板类 `Container`，它可以存储任何类型的元素。但有时候，你希望为特定类型的元素（比如**指针或数组**）提供不同的实现，因为在 `template<>` 中的符号只是类型代表符号，不能说明这个类型是什么，指针还是数组还是类，所以需要模板偏特化
```cpp
// 通用模板类
template <typename T, typename U>
class Container {
   public:
    Container(T value) : value_(value) {}
    void print() const {
        std::cout << "Generic container with value: " << value_ << std::endl;
    }

   private:
    T value_;
    U other_value_;
};

// 偏特化模板类，处理指针类型
template <typename T, typename U>
class Container<T*, U> {
   public:
    Container(T* value) : value_(value) {}
    void print() const {
        std::cout << "Pointer container with value: " << *value_ << std::endl;
    }

   private:
    T* value_;
    U other_value;
};

// 偏特化模板类，处理数组类型
template <typename T, std::size_t N, typename U>
class Container<T[N], U> {
public:
    Container(const T (&arr)[N], const U& other) : array_(arr), other_value_(other) {}
    void print() const {
        std::cout << "Array container with values: ";
        for (std::size_t i = 0; i < N; ++i) {
            std::cout << array_[i] << " ";
        }
        std::cout << ", other: " << other_value_ << std::endl;
    }

private:
    const T* array_;
    U other_value_;
};

int main() {
    Container<int, double> genericContainer(42, 3.14);
    genericContainer.print(); // 输出: Generic container with value: 42, other: 3.14

    int value = 100;
    Container<int*, std::string> ptrContainer(&value, "Hello");
    ptrContainer.print(); // 输出: Pointer container with value: 100, other: Hello

    int arr[] = {1, 2, 3, 4, 5};
    Container<int[5], int> arrayContainer(arr, 42);
    arrayContainer.print(); // 输出: Array container with values: 1 2 3 4 5 , other: 42

    return 0;
}
```

#### 函数模板全特化
函数模板没有偏特化，很简单，和[[#类模板全特化]]相似
```cpp
// 通用函数模板
template <typename T>
void printValue(const T& value) {
    std::cout << "General print: " << value << std::endl;
}

// 函数模板全特化
template <>
void printValue<std::string>(const std::string& value) {
    std::cout << "Specialized print for std::string: " << value << std::endl;
}

int main() {
    printValue(42); // 调用通用模板，输出：General print: 42
    printValue(3.14); // 调用通用模板，输出：General print: 3.14
    printValue(std::string("Hello")); // 调用全特化模板，输出：Specialized print for std::string: Hello
    return 0;
}
```
#### 语法上区别
| 特性         | 通用模板（Primary Template）              | 偏特化（Partial Specialization）         | 全特化（Full Specialization）      |
| ---------- | ----------------------------------- | ----------------------------------- | ----------------------------- |
| **模板参数列表** | `template <typename T, typename U>` | `template <typename T, typename U>` | `template <>` 不需要填写模板参数列表     |
| **模板实参列表** | `Container<T, U>`                   | `Container<T*, U>`                  | `Container<int, std::string>` |
| **适用范围**   | 所有未被特化的情况                           | 部分参数的特定实现                           | 特定的具体类型组合                     |
### 变长参数模板
是实现诸如 `std::tuple`、`std::variant` 等模板库组件的基础，参数数量不定，使用参数包 `...` 实现
```cpp
template <typename... Args>
class MyClass { /* ... */ };

template <typename T, typename... Args>
void myFunction(T first, Args... args) { /* ... */ }
```
实现变长参数函数有几种方法：
```cpp
// 递归情况：至少一个参数
template <typename T, typename... Args>
void printAll(const T& first, const Args&... args) {
    std::cout << first << " ";
    printAll(args...); // 递归调用
}

// 递归情况：至少一个参数
template <typename T, typename... Args>
void printAll(const T& first, const Args&... args) {
    std::cout << first << " ";
    printAll(args...); // 递归调用
}

// 或者折叠表达式展开， 计算参数总和
template <typename... Args>
auto sum(Args... args) -> decltype((args + ...)) {
    return (args + ...); // 左折叠
}
```
**可变参数模板**允许函数或类模板接受任意数量的模板参数。但处理参数包中的每个参数往往需要**递归模板**技巧，通常复杂且难以维护，这就需要[[Modern C++#Note：折叠表达式|折叠表达式]]来实现

## 函数模板
### 初始函数模板
```cpp
template< 形参列表 > 函数声明
```
C++17 之前，**类型 T 必须是可复制或移动才能传递参数**。C++17 以后，即使复制构造函数和移动构造函数都无效，因为 C++17 强制的复制消除，也可以传递临时纯右值
### 函数模板推导
调用函数模板时**指定形参列表时可选的**，编译器会自动推导，并且**指定的模板类型形参可能只是传入模板的参数类型的一部分**
```cpp
template <typename T>
T max(T a, T b) {
    return a > b ? a : b;
}

int main(){
    std::cout << max(3.4, 5.6); // 可以推导
}

// 如果定义为
template<typename T>
T max(const T& a, const T& b) {
	return a > b ? a : b;
}
// 使用 max(3.4, 5.6), T 会是int，但是传入max的参数是const int&
```
无法自动推导的情况：
```cpp
// 相同类型的参数传入了不同类型，主要是因为返回类型的T无法确定
using namespace std::string_literals;
int main(){
	max(1, 1.2); // Error 无法确定你的 T 到底是要 int 还是 double
	max("luse"s, "乐"); // Error 无法确定你的 T 到底是要 std::string 还是 const char[N]
}
```
![[PixPin_2025-12-30_16-50-52.png]]
解决方法是**显式定义模板参数**，注意定义的不是模板函数的返回值而是指明模板参数列表值
```cpp
std::cout << max<double>(3, 5.6);
max(static_cast<double>(1), 1.2); // 将参数类型T变为可推导
max("luse"s, std::string("乐")); // mark
```
需要注意，要使用最后一个函数，需要 `::max()` 而不能直接调用，因为 `std::max` 函数也能够用来比较 `std::string` ，这里是语意不明，而不是语法错误
