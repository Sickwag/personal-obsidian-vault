#### 调整图片和容器元素
- `modifier.fillmaxsize ()` 设置容器大小和父容器一样
- `modifier. clip()` 设置图片圆角，单位为 `dp`
##### 容器大小根据内容动态变化方法
- `Modifier.aspectRatio(16f / 9f)` 来保持容器的宽高比为 `16:9`，一般用来配合容器中图片的宽高比
- 先设置好容器的布局方向，`Column` 或者 `Row`，再使用 `Modifier.wrapContentWidth()` 和 `Modifier.wrapContentHeight()` 调整
- `contentScale = ContentScale.Fit` 确保图片按比例缩放以适应容器。（Image 函数属性）
	- 可以填入 `Inside` 表示**按比例缩放图片，使其完全适应容器，同时保持图片的原始纵横比**。
	- -`Fit` 可能会填满容器的某一维度，导致另一维度超出容器并被裁剪。
	- **`ContentScale.Crop`**：会裁剪图片以确保图片填满容器的两个维度，可能会导致图片的一部分被裁剪。
	- **`ContentScale.FillBounds`**：会拉伸图片以填满容器的两个维度，不保留原始纵横比。
- 使用`Modifier.wrapContentSize()`父容器大小将会**符合容器内容部内容**相当于 `wrap-content`
	- 如果想要在横向和纵向上更精确控制容器和其中内容的宽高效果
```kotlin
modifier = Modifier
    .size(
		// 根据内容宽度自动调整
        width = with(IntrinsicSize) { Modifier.width(IntrinsicSize.Min) },
        // 根据内容高度自动调整
        height = with(IntrinsicSize) { Modifier.height(IntrinsicSize.Min) }
    )
```
也可以直接设置容器类型为 `ConstraintLayout` 或 `BoxWithConstraints`，这样容器就会默认大小根据内容动态变化
