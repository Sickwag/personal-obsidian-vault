# 智力题
## 天平砝码
给定 `1、2、4、8、16` 五个砝码，若物体放一边、砝码只能放另一边，五个二进制权重可称出 `1` 到 `31`，共 `31` 种正整数重量。
若砝码可以放在天平两边，砝码可表示 `-31` 到 `31` 的整数差值。砝码数值仍为二进制权重；目标重量可写成“右盘砝码和减左盘砝码和”。
## 缺失元素
长度为 `n-1` 的数组包含 `1` 到 `n` 中除一个以外的所有数时，可将 `1..n` 与数组元素全部异或。相同元素两两抵消，最终结果是缺失值；时间 `O(n)`，额外空间 `O(1)`。
## 百马百担
令大马、中马、小马数量分别为 `x、y、z`，约束是 `x + y + z = 100` 与 `3x + 2y + z/2 = 100`，且 `z` 为偶数。消元得到 `5x + 3y = 100`，再枚举非负整数解；若每种马都必须至少一匹，则排除 `y = 0` 的解。
## 异常小球
每次天平称重有左重、右重、平衡三种结果。`k` 次称量最多区分 `3^k` 种结果序列；当异常球可能偏重也可能偏轻时，还要为每个球的两种状态设计互不冲突的称量编码，因此需要同时满足“球数 × 2”不超过可用编码数并排除无法自证的平衡编码。经典 `12` 球未知轻重问题可用 `3` 次称量解决。
