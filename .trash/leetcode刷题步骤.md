## 基本数据结构
### 数组
数组在内存中的结构示意图和数组的索引示意图
![[Pasted image 20250106104456.png]]
1. 连续的内存空间：数组中的所有元素都存储在**一块连续的内存区域**。
2. 固定的元素大小：由于数组中的所有元素类型相同，它们的大小也是固定的。
3. 索引访问：因为元素存储的连续性和大小的一致性，访问任何一个元素的时间复杂度都是 O (1)
4. 空间效率：在空间使用上相当高效，不需要为存储元素间的关系或位置信息额外占用内存空间。但这也意味着数组的大小在创建时需要确定，并且在其生命周期内不可改变（不考虑动态数组或类似结构）。
5. 内存分配方式：在静态数组的情况下，内存通常在编译时分配。而动态数组（如 C++中的 std:: vector 或 Java 中的 ArrayList）允许在运行时动态改变大小，内存分配发生在堆上，可以动态增长或缩减，但仍保持元素的连续存储特性。
