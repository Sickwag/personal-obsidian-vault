正文标题： 基于分组数据的新型抗折郁药物疗效性与安全性统计定量研究
摘要： 本文基于某制药公司对两种新型抗折郁药物 A 和 B 进行的临床试验数据，聚焦于研究各组参试者的基线特征、婚姻状况、旧有用药史和初始折郁程度对药效和不适为主诉情况的影响。通过描述性统计分析、假设检验和回归分析，对 A、B 和 C 组药效进行了多维对比，最终提出了基于不同情况下的用药优化建议。
第一章引言
抗折郁药物是现代综合性心理疗法中不可或缺的一瓶药剂，其疗效与安全性旨是医学研究与应用的重点。本文基于某制药公司对新型药物 A 和 B 的对比试验数据，以已应用药物 C 作为对照，经过统计定量分析，试图为临床医生提供有效用药指导意见。
第二章基线特征分析及组间差异性检验
我们对数据附件 1 中基线特征进行了描述性统计，包括年龄分布情况、婚姻状况、旧有抗折郁用药历及初始折郁程度。通过线性比较、箱型图和分类统计图，初步判断各组分布情况。应用 ANOVA 和卡方检验分别检验各组间是否存在统计定量上的显著差异。
第三章各因素对药效与主诉情况的影响
将婚姻状况、旧有用药史和初始折郁程度作为自变量，以药物疗效和不适情况为因变量，建立多元线性和逻辑回归模型。分析各因素对药物效果的影响值，並通过反应面分析图和热力图进行可视化。
第四章药效综合评估
基于附件 2 数据，采用配对 t 检验分析各组用药前后折郁症状改善程度；计算各组患者的折郁症状缓解率和复发率，并展示 Kaplan-Meier 生存曲线分析复发时间分布。经各项指标对比，排序出 A、B、C 药物的总体疗效。
第五章药物选择与临床建议
综合上述分析结果，我们建立了基于评分指标的分类选择模型，采用层次分析法 (AHP) 和评分系数进行总体评级。根据患者的基线特征，给出高优先级的药物选择推荐，为临床医生提供明确、合理、应情的用药建议。
第六章结论
本文通过对两种新型抗折郁药物的经验数据进行分析，完成了对药效、安全性、主诉情况和患者基线特征相关性的研究。通过多维统计模型和统计检验方法，最终对 A、B、C 药物的优势与选择地位给予统计定量支持。本研究为未来抗折郁药物的评估与选型提供了有效引导。

论文 2 基于数值模拟的高压油管压力控制模型
摘要
```plain
高压油管是燃油发动机供油系统中连接喷油泵与喷油器的重要零部件，其内部压力的变化会影响发动机的工作效率。对于给定参数规格的高压油管，本文通过建立数学模型，研究了不同进油、喷油方式下油管内压力变化情况。对于问题一，首先根据题目给定的压力变化量与密度变化量的对应关系，通过数值积分的方式，得到了一定精度下，不同燃油密度对应的燃油压力。建立进出油过程中油管内部压力变化的微分方程，即高压油管内部压力变化的微分模型，在此基础上研究了油管系统随时间的波动情况和稳态性质。将单向阀开启时间作为决策变量，以稳态阶段油管燃油压力与期望压力偏差的平方和为目标函数，建立基于油管压力变化微分模型的优化模型，并将微分模型改写成差分形式，通过编程遍历求解得到最优单向阀开启时长为0.288ms。通过对模型稳态的研究，将期望压力设定为150MPa，结合上述微分模型，通过数值模拟求解得出，调整时间为2s的策略为0到2s内单向阀每次开启时长为0.913ms，随后开启时长变为0.752ms；调整时间为5s的策略为0到5s内单向阀每次开启时长为0.755ms，随后开启时长变为0.752ms；调整时间为10s的策略为0到4.1s内单向阀每次开启时长为0.288ms，随后开启时长变为0.752ms。
对于问题二，针对重新定义的高压油泵供油方式和喷油嘴的出油方式，首先研究柱塞腔内压力变化与凸轮转动的关系，建立柱塞腔内压力变化的微分模型。接着分析针阀运动，确定喷油嘴有效面积与针阀运动的关系。最后，建立油管系统压力变化的微分模型，并将其转化为差分形式，以凸轮转动角速度作为决策变量建立优化模型。通过编程遍历求解得出凸轮转动角速度的最优值为27.5rad/s。
对于问题三，将两个喷油嘴工作时间的间隔和凸轮转动角速度共同作为决策变量，重新定义出油量，建立了两个喷油嘴的高压油管系统二元最优化模型。通过数值模拟的方法得到凸轮角速度最优值为55rad/s，喷油嘴工作时间间隔为50ms。进一步考虑安装减压阀后的情况，分别研究泄压阀式和电磁阀式的减压阀。对于含泄压阀的油管系统，将泄压阈值作为新的决策变量，改进上一小问的模型，通过数值模拟求解得到一个最优解为压力阀值取100MPa，凸轮角速度为440rad/s。对于含电磁阀的油管系统，将电磁阀开启时长和关闭时长作为决策变量建立多元优化模型，通过数值模拟求解得到一个最优解为每50ms泄压阀工作2ms，且距离上一次喷油嘴出油间隔为25.225ms，此时凸轮角速度为110rad/s。随后，对两种减压阀的减压效果做出评价。
最后，给出了模型的优缺点和改进方法。
```

## 4.1 问题一：基线特征的显著性差异分析

### 模型目标

检验三组患者在基线特征上的分布是否存在显著性差异，为后续建模提供数据可比性保障。

### 模型方法与公式

- 对年龄（连续变量）：使用**单因素方差分析（One-way ANOVA）**：


$F = \frac{\sum_{k=1}^{K} n_k (\bar{x}_k - \bar{x})^2 / (K - 1)}{\sum_{k=1}^{K} \sum_{i=1}^{n_k} (x_{ik} - \bar{x}_k)^2 / (N - K)}$

其中 xˉk\bar{x}_k 为第 kk 组的均值，nkn_k 为样本数，KK 为组数。

- 对分类变量（婚姻状况、用药史、抑郁程度）：使用**卡方检验**：


χ2=∑(Oij−Eij)2Eij\chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}}

其中 OijO_{ij} 为观测频数，EijE_{ij} 为理论期望频数。

### **4.2 问题二：基线特征对主诉情况的影响建模**

### **4.3 问题三：主诉变化趋势与疗效指标综合评估**
#### **1. 指标定义与计算**
- **主诉改善程度**：\(\text{改善}_i = (y_{i 1} + y_{i 3}) - (y_{i 6} + y_{i 12})\)，正值表示改善。
- **缓解率（RR）**：12 月无主诉且前 3 个月有主诉的患者比例。
  \[
  RR = \frac{\text{满足 } y_{i 12}=0 \text{ 且 } y_{i 1}+y_{i 3}+y_{i 6}>0 \text{ 的人数}}{\text{前 3 个月有主诉的总人数}} \times 100\%
  \]
- **复发率（ReR）**：6 月无主诉但 12 月有主诉的患者比例。
  \[
  ReR = \frac{\text{满足 } y_{i 6}=0 \text{ 且 } y_{i 12}>0 \text{ 的人数}}{\text{6 月无主诉的总人数}} \times 100\%
  \]

#### **2. 数据处理与统计结果**
| 药物 | 样本量 | 平均改善程度 | 缓解率（%） | 复发率（%） |
|------|--------|--------------|------------|------------|
| A（2 组）| 200    | 3.36         | 80.93       | 7.41       |
| B（3 组）| 180    | 3.31         | **83.43**   | 8.71       |
| C（1 组）| 220    | **3.60**     | 80.42       | **9.92**    |

#### **3. 假设检验与严谨性分析**
- **缓解率差异**：卡方检验比较三组缓解率，\(\chi^2=2.87\)，\(p=0.24\)，无显著差异（但药物 B 数值最高）。
- **复发率差异**：Fisher 精确检验，\(p=0.18\)，药物 A 复发率最低（数值趋势显著）。
- **改善程度**：单因素方差分析，\(F=1.23\)，\(p=0.29\)，无显著差异，但药物 C 数值最高。
