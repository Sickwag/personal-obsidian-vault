```md
# 🔍 一、推荐使用的数学方法与模型

## ✅ 方法1：多元线性回归（Multivariate Linear Regression）

### 模型形式：
$$
Y = \beta_0 + \beta_1 \cdot \text{Weeks} + \beta_2 \cdot \text{BMI} + \varepsilon
$$

### 优点：
- 简洁直观，便于解释；
- 可直接进行t检验判断每个变量的显著性；
- 是后续复杂模型的基础。

### 显著性检验：
- **t检验**：对每个系数 $\beta_i$ 进行显著性检验（$H_0: \beta_i = 0$）
- **F检验**：整体模型是否显著（所有自变量联合解释能力）

### 实现方式（Python示例）：

import statsmodels.api as sm

# 准备数据
X = data[['检测孕周', '孕妇BMI']]
X = sm.add_constant(X)  # 添加截距项
y = data['Y染色体浓度']

# 拟合模型
model = sm.OLS(y, X).fit()
print(model.summary())

📌 输出中关注：
- `P>|t|` 判断单个变量是否显著（p < 0.05 表示显著）
- `R-squared` 解释程度
- `F-statistic` 和对应p值判断整体显著性

## ✅ 方法2：多项式回归 / 非线性趋势建模

如果你的散点图显示 **Y浓度随孕周呈S型增长，或随BMI呈下降趋势但非线性**，建议引入**非线性项**。

### 模型形式（举例）：
$$
Y = \beta_0 + \beta_1 \cdot W + \beta_2 \cdot W^2 + \beta_3 \cdot B + \beta_4 \cdot B^2 + \beta_5 \cdot W \cdot B + \varepsilon
$$
其中 $W$ = 孕周，$B$ = BMI

这可以捕捉：
- Y浓度随孕周先慢后快增长（二次项）
- 随BMI增加而加速下降（二次项）
- 孕周与BMI的协同效应（交互项）

> 💡 提示：如果发现高BMI孕妇在早期Y浓度极低，后期才缓慢上升，说明存在“延迟达标”现象，交互项很重要！

### 实现方式：

from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(data[['检测孕周', '孕妇BMI']])
X_poly = sm.add_constant(X_poly)
model_poly = sm.OLS(y, X_poly).fit()
print(model_poly.summary())

## ✅ 方法3：广义可加模型（GAM, Generalized Additive Model）

如果你怀疑关系是**高度非线性但无法用多项式很好拟合**，可用GAM。

它允许每个变量以“平滑函数”形式进入模型：
$$
Y = \beta_0 + f_1(\text{Weeks}) + f_2(\text{BMI}) + \varepsilon
$$

### 优点：
- 自动学习非线性趋势；
- 可视化平滑函数形状；
- 更灵活于真实生理过程。

### Python实现（使用`pygam`库）：

## ✅ 方法4：混合效应模型（Mixed Effects Model）

由于**同一个孕妇有多次检测记录**（如A001测了4次），观测值之间不独立，违反了普通回归的独立性假设。

✅ 应使用**线性混合效应模型（LMM）**，将“孕妇代码”作为随机效应。

### 模型形式：
$$
Y_{ij} = \beta_0 + \beta_1 W_{ij} + \beta_2 B_i + u_i + \varepsilon_{ij}
$$
其中 $u_i \sim N(0, \sigma_u^2)$ 是第 $i$ 个孕妇的随机截距。

### 优势：
- 控制个体差异（如某些人天生Y浓度偏低）；
- 更准确的标准误和p值；
- 更适合纵向数据（重复测量）

### Python实现（使用`statsmodels`）：

import statsmodels.api as sm
import statsmodels.formula.api as smf

# 转换为DataFrame便于公式操作
df = data[['孕妇代码', '检测孕周', '孕妇BMI', 'Y染色体浓度']].dropna()

# 拟合混合效应模型（随机截距）
md = smf.mixedlm("Y染色体浓度 ~ 检测孕周 + 孕妇BMI", df, groups=df["孕妇代码"])
fit_md = md.fit()
print(fit_md.summary())


📌 关注：
- 固定效应（Fixed Effects）的系数和p值；
- 随机效应方差（Std group / Std resid）是否显著。

# 📊 二、显著性检验总结

| 方法 | 检验方式 | 判断标准 |
|------|---------|----------|
| 多元线性回归 | t检验（单变量）、F检验（整体） | p < 0.05 显著 |
| 多项式/交互项 | t检验各项 | 二次项/交互项显著说明非线性 |
| GAM | 置信带是否包含0 | 曲线远离0则显著 |
| 混合模型 | 固定效应t检验 + 似然比检验（AIC/BIC） | p < 0.05，AIC更低更优 |
```

### 输出结果
```md
你有一列形如 `28w+3`、`27w`、`26w+6` 等的数据，格式为：

a w + b

其中：
- `a` 是周数（整数）
- `b` 是额外的天数（可选，如果没有则为 0）
- 要转换为小数：`a + b/7`

例如：
- `28w+3` → `28 + 3/7 ≈ 28.4286`
- `27w` → `27 + 0/7 = 27`
- `26w+6` → `26 + 6/7 ≈ 26.8571`

---

### ✅ 解决方案：使用 Excel 公式

你可以使用 **文本处理函数** 来提取 `a` 和 `b`，然后计算 `a + b/7`。

假设你的数据在 **A 列**（从 A2 开始），可以在 B2 输入以下公式：

=LET(
    text, A2,
    a, VALUE(LEFT(text, FIND("w", text) - 1)),
    b_part, IF(ISNUMBER(FIND("+", text)), MID(text, FIND("+", text) + 1, LEN(text)), 0),
    b, IF(b_part="", 0, VALUE(b_part)),
    a + b / 7
)

---

### 🔍 公式说明：

1. `FIND("w", text)` 找到 "w" 的位置
2. `LEFT(text, FIND("w", text) - 1)` 提取 `a`（即 w 前面的数字）
3. `FIND("+", text)` 查找 "+" 是否存在
4. 如果有 `+`，提取其后的数字作为 `b`；否则设为 0
5. 最后计算 `a + b/7`

---

| 原始数据 | 转换结果 |

| 28w+3  | 28.42857 |

| 28w+1  | 28.14286 |
| 27w    | 27.00000 |

| 26w+3  | 26.42857 |
| 26w    | 26.00000 |

---

### ⚠️ 注意事项：

- 数据必须是文本格式（不是数值）
- 没有空格，且格式统一（如 `28w+3`，不是 `28 w + 3`）
- 如果数据中可能包含其他字符（比如单位、空格等），需调整公式

这个公式适用于 Excel 2010 及以上版本（不含 LET 函数）。
```

```md
#### 2.1 问题一的分析

本问题旨在探究胎儿Y染色体浓度与孕妇孕周数、BMI等指标的相关特性，构建具有统计显著性的数学模型。Y染色体浓度是评估NIPT检测可靠性的关键指标，其值达到或超过4%时可认为结果可信。因此，明确浓度随孕周及BMI的变化规律，对后续确定最佳检测时点具有重要意义。

由于每位孕妇可能存在多次采样记录，观测数据呈现**纵向重复测量结构**，同一孕妇的不同检测结果之间存在组内相关性，违反普通回归模型的独立性假设。若忽略该相关性，将导致标准误低估与参数显著性虚高。为此，本文采用**线性混合效应模型**（Linear Mixed Effects Model, LMM），引入以“孕妇代码”为分组变量的随机截距项，以捕捉个体间的基线差异，提升模型估计的稳健性。

在建模前，首先进行数据预处理：将“检测孕周”（如“11w+6”）统一转换为十进制周数；剔除Y染色体浓度为负值或明显异常的样本；结合箱线图与临床常识识别并处理极端离群值。通过散点图与分组趋势图观察发现，Y染色体浓度总体随孕周增加呈近似线性上升趋势，且高BMI孕妇的浓度增长速率更快，提示可能存在**孕周与BMI的交互效应**。

基于上述探索，建立包含主效应与交互项的线性混合效应模型：
$$
Y_{ij} = \beta_0 + \beta_1 \cdot \text{孕周}_{ij} + \beta_2 \cdot \text{BMI}_i + \beta_3 \cdot (\text{孕周} \times \text{BMI}) + u_i + \varepsilon_{ij}
$$
其中 $ Y_{ij} $ 表示第 $ i $ 个孕妇第 $ j $ 次检测的Y染色体浓度，$ u_i \sim N(0, \sigma_u^2) $ 为随机截距，反映个体间异质性。

模型显著性通过t检验与似然比检验（Likelihood Ratio Test, LRT）进行验证，并结合残差QQ图与散点图检验正态性与同方差性假设。最终模型不仅揭示变量间的定量关系，也为后续分组优化提供理论支持。
```
