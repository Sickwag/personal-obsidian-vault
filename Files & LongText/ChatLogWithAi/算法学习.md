## 🧠 回溯算法通用模板
```cpp
void backtrack(参数) {
    if (终止条件) {
        存放结果;
        return;
    }
    for (选择：本层集合中元素（树中节点孩子的数量就是集合的大小）) {
        处理节点;
        backtrack(路径, 选择列表); // 递归
        回溯，撤销处理结果;
    }
}
```

## 一、组合问题
### 📌 题型特点：
从 N 个数中选出 k 个数，满足某种条件（如和为 target，或任意组合）。
### ✅ 实例：
**LeetCode 77. 组合**：找出所有可能的 1~n 中 k 个数的组合。
### 🧩 解法：
```cpp
vector<vector<int>> combine(int n, int k) {
    vector<vector<int>> res;
    vector<int> path;
    backtrack(1, n, k, path, res);
    return res;
}
void backtrack(int start, int n, int k, vector<int>& path, vector<vector<int>>& res) {
    if (path.size() == k) {
        res.push_back(path);
        return;
    }
    for (int i = start; i <= n; ++i) {
        path.push_back(i);
        backtrack(i + 1, n, k, path, res);
        path.pop_back();
    }
}
```
### 🧠 思考方法：
- 每次从当前起点往后选
- 剪枝条件：path.size() == k
- 注意去重（避免重复组合）

## 二、切割问题
### 📌 题型特点：
将字符串按一定规则切割，找出所有可能的合法切割方式。
### ✅ 实例：
**LeetCode 131. 分割回文串**：给定一个字符串，将其分割为若干子串，每个子串都是回文。
### 🧩 解法：
```cpp
vector<vector<string>> partition(string s) {
    vector<vector<string>> res;
    vector<string> path;
    backtrack(0, s, path, res);
    return res;
}
void backtrack(int start, string& s, vector<string>& path, vector<vector<string>>& res) {
    if (start == s.size()) {
        res.push_back(path);
        return;
    }
    for (int i = start; i < s.size(); ++i) {
        if (isPalindrome(s, start, i)) {
            path.push_back(s.substr(start, i - start + 1));
            backtrack(i + 1, s, path, res);
            path.pop_back();
        }
    }
}
bool isPalindrome(string& s, int l, int r) {
    while (l < r) if (s[l++] != s[r--]) return false;
    return true;
}
```
### 🧠 思考方法：
- 从 start 开始尝试切到 i
- 判断 s[start..i] 是否符合切割条件（如回文）
- 若符合，递归处理 i+1 后的部分

## 三、子集问题
### 📌 题型特点：
找出集合中所有可能的子集（或满足某些条件的子集）。
### ✅ 实例：
**LeetCode 78. 子集**：返回所有可能的子集（幂集）。
### 🧩 解法：
```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    vector<vector<int>> res;
    vector<int> path;
    backtrack(0, nums, path, res);
    return res;
}
void backtrack(int index, vector<int>& nums, vector<int>& path, vector<vector<int>>& res) {
    res.push_back(path);  // 每个节点都是一个子集
    for (int i = index; i < nums.size(); ++i) {
        path.push_back(nums[i]);
        backtrack(i + 1, nums, path, res);
        path.pop_back();
    }
}
```
### 🧠 思考方法：
- 每个节点都代表一个子集
- 从 index 开始选，避免重复子集
- 不需要终止条件，每次递归都收集结果

## 四、排列问题
### 📌 题型特点：
找出所有可能的排列（顺序不同视为不同解）。
### ✅ 实例：
**LeetCode 46. 全排列**：给定一个不含重复数字的数组，返回所有可能的排列。
### 🧩 解法：
```cpp
vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> res;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    backtrack(nums, used, path, res);
    return res;
}
void backtrack(vector<int>& nums, vector<bool>& used, vector<int>& path, vector<vector<int>>& res) {
    if (path.size() == nums.size()) {
        res.push_back(path);
        return;
    }
    for (int i = 0; i < nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(nums[i]);
        backtrack(nums, used, path, res);
        path.pop_back();
        used[i] = false;
    }
}
```
### 🧠 思考方法：
- 使用 used 数组标记已选元素
- 每个位置都可选未被选过的元素
- 终止条件为 path.size() == nums.size()

## 五、棋盘问题
### 📌 题型特点：
涉及棋盘布局、状态判断、剪枝优化。
### ✅ 实例：
**LeetCode 51. N皇后**：在 N×N 棋盘上放置 N 个皇后，使得彼此不能互相攻击。
### 🧩 解法（简化）：
```cpp
vector<vector<string>> solveNQueens(int n) {
    vector<vector<string>> res;
    vector<string> board(n, string(n, '.'));
    vector<bool> cols(n, false), diag1(2*n, false), diag2(2*n, false);
    backtrack(0, n, board, cols, diag1, diag2, res);
    return res;
}
void backtrack(int row, int n, vector<string>& board, vector<bool>& cols,
               vector<bool>& diag1, vector<bool>& diag2, vector<vector<string>>& res) {
    if (row == n) {
        res.push_back(board);
        return;
    }
    for (int col = 0; col < n; ++col) {
        if (cols[col] || diag1[row - col + n] || diag2[row + col]) continue;
        cols[col] = diag1[row - col + n] = diag2[row + col] = true;
        board[row][col] = 'Q';
        backtrack(row + 1, n, board, cols, diag1, diag2, res);
        board[row][col] = '.';
        cols[col] = diag1[row - col + n] = diag2[row + col] = false;
    }
}
```
### 🧠 思考方法：
- 按行放置皇后
- 使用辅助数组记录列、主对角线、副对角线是否冲突
- 每次递归尝试所有列，剪枝非法位置

## 🌲 回溯算法决策树（通用思路）
```text
面对回溯题时的思考路径：
1. 问题类型识别
   ├─ 组合？排列？子集？切割？棋盘？
   └─ 是否有重复元素？是否需要剪枝？
2. 是否需要排序？
   ├─ 去重需要排序（如组合总和II）
   └─ 优化剪枝时也可能排序
3. 递归参数设计
   ├─ 当前路径 path
   ├─ 起始位置 index（组合、切割）
   ├─ 使用标记 used（排列）
   └─ 其他辅助变量（如括号数量、棋盘状态）
4. 终止条件判断
   ├─ 路径长度达标？
   ├─ 起始位置越界？
   └─ 满足某种条件？
5. 剪枝优化
   ├─ 提前判断当前选择是否合法
   └─ 比如括号数量、皇后冲突、数字和等
6. 收集结果
   ├─ 每个递归节点都可能是一个解
   └─ 有些题只在叶子节点收集结果
7. 回溯撤销
   ├─ push_back 后要 pop_back
   └─ used[i] = true 后要设为 false
```

## 🧩 面对回溯题时的决策树（图解式）
```text
开始
 │
 ├─ 问题类型？
 │   ├─ 组合 → 起始位置 + 无重复
 │   ├─ 排列 → used数组 + 全排列
 │   ├─ 子集 → 每个节点都是解
 │   ├─ 切割 → 每次切到i，判断[start..i]是否合法
 │   └─ 棋盘 → 位置合法性判断（如N皇后）
 │
 ├─ 是否有重复元素？
 │   ├─ 是 → 剪枝去重（排序 + index跳过）
 │   └─ 否 → 直接处理
 │
 ├─ 是否需要剪枝？
 │   ├─ 是 → 提前判断当前选择是否合法
 │   └─ 否 → 全部尝试
 │
 ├─ 递归参数设计？
 │   ├─ path（当前路径）
 │   ├─ start/index（起始位置）
 │   ├─ used数组（排列）
 │   └─ 其他辅助结构（如栈、计数器）
 │
 ├─ 终止条件？
 │   ├─ 路径长度达标？
 │   └─ 起始位置越界？
 │
 └─ 收集结果？
     ├─ 每次递归都收集（子集）
     └─ 只在终止条件收集（组合、排列）
```
