自底向上归并：middle 与 last 到底怎么切

代码是两个 min：middle = first + min(width, count - first)，last = middle + min(width, count - middle)。下面把每一轮的组边界画出来。

每组合并相邻两段：左段 [first, middle)，右段 [middle, last)。每段最多 width 个元素，但不能超过数组剩下的元素。

写法middlelast结果
first + width 4 + 2 = 6 6 + 2 = 8 端点 6、8 都超过 count = 5，访问 values[5] 越界
first + min(width, count - first) 4 + min(2, 1) = 5 5 + min(2, 0) = 5 左段 [4,5)，右段为空，只复制一个元素

min 不是防御性代码，它是“最后一组只剩几个元素”和“右段可能为空”这两件事的唯一正确表达。

一句话总结

每一轮按 2×width 切组；每组左段取 min(width, count-first) 个，右段取 min(width, count-middle) 个。count 能整除 2×width 时每组刚好满；除不尽时最后一组先短在左、再短在右，右段可能为空。端点永远落在 [0, count] 内，所以 first、middle、last 都不会越界。
