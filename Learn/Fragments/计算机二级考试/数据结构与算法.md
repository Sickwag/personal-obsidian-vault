- 数据结构域存储结构并不是一一对应的

    **逻辑结构**是指数据元素之间的逻辑关系，包括线性结构和非线性结构。这些逻辑关系是从具体问题抽象出来的，反映了问题本身的性质。

    **存储结构**是指数据在计算机内存中表示，也就是实际存储在计算机中形式，包括顺序存储、链式存储、索引存储和散列存储。

    虽然存储结构是逻辑结构在计算机内存中实现，但并不是一一对应的。例如，线性表的逻辑结构可以通过顺序存储结构（如数组）或链式存储结构（如链表）来实现。同样，树形结构的逻辑结构可以通过顺序存储结构或链式存储结构来实现。

    因此，数据的逻辑结构和存储结构是密切相关的，它们共同决定了数据的组织方式，以满足不同的数据处理需求。但，它们并不是一一对应的。

    [判断一个序列是否是堆，可以按照以下步骤进行](https://zhuanlan.zhihu.com/p/262952475)[3](https://blog.csdn.net/u011240877/article/details/47706923)[4](https://bing.com/search?q=%E5%A6%82%E4%BD%95%E5%88%A4%E6%96%AD%E4%B8%80%E4%B8%AA%E5%BA%8F%E5%88%97%E6%98%AF%E4%B8%8D%E6%98%AF%E5%A0%86)：

    1. 将序列看作一棵完全二叉树。
    2. 从最后一个非叶子节点开始，从右到左依次检查每个节点是否满足堆的性质。
    3. 如果所有节点都满足堆的性质，则序列是堆，否则不是堆。

    这里的“堆的性质”指的是：

    - 对于最大堆，每个节点的值都大于或等于其子节点的值。
    - 对于最小堆，每个节点的值都小于或等于其子节点的值。

    也就是说，每一个堆其中元素要么从大到小排列，要么从小到大，堆中每一个元素都是节点，不过注意，每一个堆的都是一个完全二叉树，阅读方法：

    **`heap = [9, 5, 6, 4, 3, 2]`**

    这个序列可以被视为一个最大堆，其中每个元素都是一个节点。在这个堆中，父节点的值总是大于或等于其子节点的值。

    - `**9**` 是根节点，它的子节点是 `**5**` 和 `**6**`。
    - `**5**` 是 `**9**` 的左子节点，它的子节点是 `**4**` 和 `**3**`。
    - `**6**` 是 `**9**` 的右子节点，它的子节点是 `**2**`。
    - `**4**`、`**3**` 和 `**2**` 是叶子节点，它们没有子节点。
- 关于队列数据结构和溢出

    循环队列属于队列的特例和栈同属于线性结构。
    在顺序队列中，由于数组空间不够而产生的溢出叫
    **真溢出**；
    顺序队列因多次入队列和出队列操作后出现的有存储空间但不能进行入队列操作的溢出称为
    **假溢出**；
    假溢出是由于队尾rear的值和队头front的值不能由所定义数组下界值自动转为数组上界值而产生的，解决的办法是把顺序队列所使用的存储空间构造成一个逻辑上首尾相连的循环队列。
    因此，顺序队列通常都采用顺序循环队列结构；
    栈的存储方式有顺序存储和链式存储。循环队列虽然能解决假溢出，却不能解决在顺序队列中，由于数组空间不够而产生的真溢出。

    算法的运算

    最坏情况下的时间复杂度称为最坏时间复杂度。一般不特别说明，讨论的时间复杂度均是最坏情况下的时间复杂度。

    **最坏情况下的时间复杂度**是算法在任何输入实例上运行时间的上界，这就保证了算法的运行时间不会比任何情况更长。

    **平均时间复杂度**是指所有可能的输入实例均以等概率出现的情况下，算法的期望运行时间。
    在输入不同的情况下算法的运行时间复杂度可能会发生变化。平均时间复杂度给出了算法的期望运行时间，有助于算法好坏的评价以及在不同算法之间比较时有一个统一标准。
    在顺序存储的线性表中寻找最大项，其平均情况与最坏情况下的时间复杂度都是n/2。
