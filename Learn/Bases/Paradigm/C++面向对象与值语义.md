# C++ 面向对象与值语义
参考：[[C++开发范式和术语#RAII 机制]]、[[Modern C++#第 2 章语言可用性的强化]]
## C++ 是多范式语言
C++ 支持过程式、面向对象、泛型和函数式编程。类与继承是可组合使用的工具，不要求所有数据都通过堆上的对象引用访问，也不要求所有逻辑都放入虚函数体系。
## 值语义与引用语义
值语义把对象状态作为值处理，拷贝会得到独立对象；C++ 可让对象具有自动、静态或动态存储期，并用移动语义降低转移资源的成本。引用语义通过引用或指针访问已有对象，使多个调用方共享身份和可变状态。
语言差异不能简化为“Java 参数按引用传递”：Java 方法参数本身按值传递；对象变量的值是引用，因此复制参数会复制引用，而不是复制对象。C++ 则允许对象值、引用和指针作为不同接口语义。
## 面向对象的作用
- 封装用访问控制和稳定接口限制变更影响面；`friend` 等机制会显式扩大访问范围。
- 继承表达可替换的“is-a”关系并复用接口；不满足替换关系或层次复杂时优先组合。
- 动态多态让调用方依赖抽象接口；编译期多态（模板、重载、CRTP）可在编译期选择实现。
评估设计时关注变更传播范围、所有权和对象生命周期，而不只看类型是否映射现实实体。算法密集的数据操作常用泛型；状态转换可用过程或状态机；需要稳定接口替换实现时再使用运行时多态。
