# PostgreSQL SSI
## 可串行化快照隔离
可串行化快照隔离（Serializable Snapshot Isolation，SSI）在 MVCC 快照隔离之上追踪读写依赖，检测可能导致不可串行化结果的事务组合，并中止其中一个事务，而不是用传统两阶段锁阻塞所有冲突读写。
事务读取某行或谓词范围后，并发事务写入相关数据会形成读写反依赖（rw-antidependency）。若依赖关系构成危险结构，数据库会让某个事务以序列化失败结束，避免写偏斜等快照隔离异常。
SSI 的读不会像传统共享锁那样阻塞写入，但系统仍需记录读依赖（PostgreSQL 使用 SIREAD predicate lock 机制），并承担冲突检测与内存开销。只读事务在满足安全快照条件时可减少后续跟踪。
调用方必须把序列化失败视为正常并发结果，并重试完整事务。事务中若直接执行邮件、支付等外部副作用，重试可能重复操作；应将副作用放到事务外，通过 Outbox 或幂等接口处理。
